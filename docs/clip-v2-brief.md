# 派工單：把一支識字動畫照 v2 重做

給負責寫的子代理（Opus 5.5）。監督者（Fable）會親自看你的總覽圖驗收。一次只做指定的那一個字。
爸爸退過件的原因是「笑點不明顯」，所以最重要的是**一個一眼看得懂的主軸笑點**。

## 先確認能不能做
先跑 `node scripts/anim-v2-next.mjs <字>`：印出「可以做」才繼續；如果說有上架影片或已經是 v2，**什麼都不要改**，直接回報。

## 先讀（依序）
1. `AGENTS.md`
2. `docs/clip-v2-plan.md`（v2 規格：時間表、規則、「只有一個主軸笑點」、固定明星、一支的流程）
3. `.claude/skills/char-animation/SKILL.md`（「v2 片型」一節、**「主角」一節的姿勢表**、引擎速查、anim:shot 與 5b 的三輪流程）
4. v2 樣板——照它們的結構：把同一個笑點寫成函式、呼叫四次：`src/anim/clips/貓.ts`（`swat()`）、`冷.ts`（`freeze()`）、`蝦.ts`（`snap()`）、`捷.ts`、`睿.ts`；`src/anim/parts.ts`
5. `src/anim/clips/<字>.ts`（現在的 v1）；跑 `npm run anim -- <字>` 看筆畫與語詞

## 每支都要守的
- **動手前先用一句話寫下笑點**，確認它不用解釋就看得懂。同一個動作／原因／音效做三次、只有結果變大、第三次前停一拍讓小孩猜到、回馬槍是同一個笑點的第四次帶反轉。
- **笑點要演出這個字的意思**（冷＝被凍住、蝦＝尾巴一彈跳開），不是隨便一個整人橋段。
- 這個字講的東西要是畫面上最大、最中間的。角色最多 3 個、道具最多 2 個。片長 12～15 秒。
- 明星有 27 個姿勢（SKILL.md 有表）：伸手 `reach`、等回答 `listen`、回答 `point`、被壓扁 `flat`、傻眼 `surprised`、衝刺 `dash`、跌坐 `fall` ⋯⋯**用姿勢演，不要用 emoji 符號代替表情**。圖都朝左，要面向右邊的東西就 `flip: true`；每一輪都檢查他有沒有背對該看的東西。
- 那一下要有重量：預備看得到、發生那格鏡頭 punch＋shake、傻眼的臉停得住 0.4 秒以上；效果符號要夠大、在淺色背景上看得清楚（💨 的圖很淡，不要靠它當主要訊號）。
- **語詞那一刻**唸到的東西和明星要在畫面中間、最大，不是縮在角落。
- 國字讓位到自訂位置時，自動取景可能把國字切掉一角：每一輪都檢查國字整個在畫面裡。鏡頭 punch 時畫面邊緣的重要東西不要被切掉。
- **沒有合適 emoji 的東西不要硬湊**（楊桃不能用 ⭐、打開的禮物不能用 📦）：先查 `public/props/`（`emoji: 'prop:<名字>'`，SKILL.md「自製道具圖」一節）；
  沒有就先用最接近的頂著，並在回報裡列出需要的道具（一句話描述長相、朝向），由監督者請 Codex 生。
- 部件顏色照 `parts.ts`；表裡沒有的先登記（照表頭規矩，跟現有的顏色要分得開）。部件分 2～3 組，對應前三次。

## 流程
1. 現有 `src/anim/clips/<字>.ts` 複製到 `src/anim/clips-old/<字>.ts`（已存在就蓋掉），拍舊版總覽 `--old --tag old`。
2. 重寫 `src/anim/clips/<字>.ts`（`format: 2`）。
3. `anim:shot` 看總覽至少三輪（`--tag r1`…），每輪一行「看到什麼、改了什麼」；每一次笑點的前後用 `--from/--to --step 0.1` 細看，確認四次長得一樣。用到新 emoji 先跑 `npm run emoji3d`。
4. 驗收：`npx tsc -b`、`npm test`、`npm run anim:check`（全部，不能有新的錯誤）、`npm run anim:check -- <字>` 0 錯 0 注意、`npm run app:build`。
5. 產出：最終總覽 `--tag final --width 320 --cols 6 --rows 11`（整支塞一張）、四次笑點逐格對照圖（一張）、新舊並排 mp4（`.anim-shots/<字>-old-vs-new.mp4`，舊版較短就補最後一格）。

## 收尾：不要留用不到的檔
交卷前把 `.anim-shots/` 裡這個字的中間產物刪掉（`r1`、`r2`⋯⋯各輪總覽、細看片段、舊版總覽、單支 mp4），**只留三個**：最終總覽、四次笑點逐格對照、`<字>-old-vs-new.mp4`。前兩張監督者驗收完會再刪，最後只留並排影片。暫存資料夾裡自己產生的東西也清掉。

## 不要做
- 不要 git add／commit／push；不要改其他劇本；不要動 `data/`；不要開 5180 玩（只用 `anim:shot`）；不要引入外部網址。
- 引擎（`clip.ts`／`AnimPlayer.tsx`）盡量不動；真的缺一個小效果才加，加了要補測試、且不能改變任何現有劇本的畫面。
- `docs/clip-v2-plan.md` 不要改（進度表監督者來填）；SKILL.md 只有在你加了引擎功能時補速查。
- repo-context 的留痕由監督者做，你不用做。
