# 品質躍進計畫：動畫與遊戲（2026-11-10 起）

目標：動畫和遊戲要「顯著」變好，不是再多做幾支。判準是小孩會不會要求重看、重玩。

## 為什麼之前卡住
1. **寫動畫的人看不到成品**。劇本是一行行座標和秒數，Chrome 分頁在背景時動畫不會跑，只能一格一格定格截圖。時機、節奏、笑點有沒有停夠，沒有人整支看過。
2. **角色是整張貼紙**。主角是每個姿勢一張 PNG，只能整張平移、旋轉、壓扁、換圖。播放器已經自動加了呼吸、速度線、殘影、拉伸，但走路沒有步伐、換姿勢是硬切、講話時不會動、停下來沒有跟隨動作。
3. **量多於精**。189 支劇本、20 幾個遊戲元件，每支打磨很少；哪些真的讓他想再玩，沒有資料。

## 四個階段（依序，一次一個，每階段做完由規劃者看過成品才往下）

### 階段 1：看得見成品（`npm run anim:shot`）
- 用這台 Mac 的 Chrome 在背景開真正的播放器（`/anim?char=字&t=秒`），逐格截圖。**不另寫一套畫法**，之後換角色畫法工具照樣能用。
- 產出：一張縮圖總覽（每 0.25 秒一格、每格標秒數，一眼看完整支的節奏）＋可選的 mp4。輸出到 repo 外或 `.gitignore` 掉的資料夾。
- 不引入外部網址；可以加 devDependency（不進 App）。不能寫到小孩的紀錄。
- 驗收：對 3 個字跑得出總覽，圖上看得出每一拍；`char-animation` 的 SKILL.md 第 5 步改成用它。

### 階段 2：角色動起來像卡通（引擎自動加，189 支一起受惠）
全部維持「畫面只由 t 決定」的純函式。劇本不用改就會變好：
- **走路有步伐**：在地上水平移動時自動左右搖擺＋上下顛，步頻跟速度走。
- **換姿勢不硬切**：swap 的瞬間有一下擠壓彈出。
- **講話會動**：唸字那一拍，最近有動作的主角點頭彈一下。
- **跟隨動作**：急停、落地後身體往前傾再晃回來；把貼紙切成幾段橫條，上半身晚一點跟上（軟Q感）。
- **自動落地**：從空中落到地板自動壓扁＋揚塵（劇本已經寫了的不重複）。
- 驗收：同一支劇本改前改後各出一張總覽與 mp4 並排比；`npm test`、`npx tsc -b`、`npm run anim:check`、`npm run app:build` 全過；iPad 上不能掉格（每格運算量要量過）。
- 這一階段做完如果貼紙的上限還是很明顯，再評估要不要重畫成分件角色（頭、手、眼、嘴分開）。那要重做 17 個主角的圖，先不做。

### 階段 3：三支動畫重做到頂（A/B）
- 挑 3 個「孩子端看得到、沒有上架影片、所以他真的會看到動畫」的字。
- 每支用階段 1 的工具反覆看、反覆改：笑點前的停頓、預備動作、反應鏡頭、結尾回馬槍。至少改三輪，每輪寫下「看到什麼問題、改了什麼」。
- 舊版留著（`/anim?char=字&v=old`），新舊各出一支 mp4 給爸爸看；給小孩盲看時看他要求重看哪一支。
- 把學到的寫回 SKILL.md，之後每支都照這個流程。

### 階段 4：遊戲手感（挑兩個，不加新遊戲）
- 用 `npm run play`（隔離資料）實際玩魔法筆和餵大怪獸，各列出回饋最弱的 5 個瞬間：點了沒反應、答對不夠爽、答錯不清楚、等待的空白、不知道下一步。
- 逐一補：按下的即時回饋、答對的聲光與夥伴反應、過場不留空白。固定句照規矩放 `shared/voice-lines.mjs`。
- 驗收：改前改後截圖對照；四種尺寸掃一遍；測試全過。

## 還不知道的
- 小孩對現有動畫的反應沒有資料。階段 3 的盲看是唯一的驗證，要爸爸陪看。
- 聲音（配音、音效好不好聽）agent 聽不到，每階段都要爸爸戴耳機確認。

### 重做一支的派工方式
一次一支、一個 agent：讀 SKILL.md 與兩支範本（爬、睿）→ 出舊版總覽列問題 → 舊劇本複製到 clips-old → 重寫 → 看總覽改至少三輪 → `anim:check` 0 錯 0 注意 → 規劃者抽看定稿總覽後 commit。一支約 6 分鐘。
每支都要守的（今晚踩過的）：盡量保留舊卡司；唸到什麼畫面上就要看到什麼；道具一眼認得出來；白光不低於 -0.5；用到新 emoji 先跑 `npm run emoji3d` 再出總覽。

### 還不夠好、要爸爸看的
- **黑**：語詞「黑熊」，畫面上是全黑的怪獸，不是熊。
- **龜**：「綠寶石」是染綠的哈密瓜，烏龜探出頭之前看不懂。
- **冷**：卡司整組換了（舊版是積木小隊＋小老鼠，新版是小恐龍＋企鵝）。
- **森**：煙霧彈用 💣 畫。
- **晚**：10 秒塞四段戲，結尾最擠。
- **每支共同的弱點**：國字拼好後停留的那 0.8 秒，角色在兩側戲小；讓位後鏡頭推不近，角色仍偏小。這是整張貼紙角色加上「國字要大」的上限，再往上要重畫成分件角色。
- **聲音都沒人聽過**：每支的音效搭配、語詞發音，還有遊戲裡連對第 3 個起疊的音效會不會蓋到唸詞。

### 沒驗證完的
補了 85 張 3D 道具圖之後，約 90 支沒重做的舊劇本畫面也跟著換圖。朝向與顏色逐張看過並修了（🤏、🟫、🧆、🥥），但每支裡的大小位置只抽查 10 支，約 80 支沒逐支看。之後重做到那一支時自然會看到。
