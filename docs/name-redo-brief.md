# 派工單：把主角館的一支名字動畫加強重做

給負責寫的子代理（Opus 5.5）。監督者（Fable）會親自看你的總覽圖驗收。一次只做指定的那一個名字。
爸爸看完說「主角館的影片品質比較差」。對照識字動畫 v2，舊片的毛病是：

1. **角色太小**：主角在畫面上只有一點點，鏡頭大半時間是全景。
2. **小笑點太多、沒有主軸**：10 秒塞四五件不相干的事，遮掉字幕看不懂在演什麼。
3. **表情靠飄在頭上的 emoji**（😳😆😑❓）和小到看不見的想法泡泡，不是角色自己在演。
4. **道具用小小的 emoji 湊**，明明 `public/props/` 有畫好的大圖。

## 加強版的標準
- **動手前先用一句話寫下主軸笑點**，不用解釋就看得懂，而且演的是名字的字面意思。
  **同一個動作、同一個原因、同一個音效做三次，只有結果越來越大；第三次前停一拍讓他猜到；最後一次帶一個反轉**，接亮相。
  舊片裡跟主軸無關的支線（路過的鳥、想法泡泡、多的配角）全部拿掉。舊片的點子好就留著當主軸，不好就換。
- **角色要大**：主角 size 32～38（站在地上 `y = 77 − 0.42 × size`），對手不小於 20；戲在畫面中間（x 45～115）。
  自動取景拉不近就自己寫 `zoom`；整支大部分時間主角高度佔畫面三成以上，亮相時四成以上。
- **用姿勢演**：自家主角有幾十個姿勢（surprised、fall、flat、reach、dash、giggle、bow⋯⋯），圖都朝左，面向右邊的東西要 `flip: true`。
  **不要在頭上飄表情 emoji**；效果符號（💥⭐💦）可以用，但要夠大、在這個背景上看得清楚。
- **道具先查 `public/props/`**（`emoji: 'prop:<名字>'`），有大圖就不要用小 emoji。沒有合適的圖不要硬湊，先用最接近的頂著，回報裡寫需要什麼圖（一句話描述長相、朝向）。
- 角色最多 3 個、道具最多 3 個，背景道具另算但不要搶戲。
- 片長 8～12 秒（`names:check` 放寬到 12 秒）。剛好一句 `say`＝名字，落在亮相、主角最大最清楚那一刻；亮相停 0.8 秒以上。
- 那一下要有重量：預備看得到、發生那格 `punch`＋`shake`、傻眼的姿勢停得住 0.4 秒以上。白光最多 `-0.5`，閃光不要把畫面整片刷白。
- 所有權：只演字面意思，卡司跟舊片同一個方向（舊片刻意不用某個自家主角的，照舊不用）；檔頭第一行「演的是字面意思：……」保留並更新。

## 流程
1. 先拍舊版：`npm run anim:shot -- --name <id> --tag old --width 320 --cols 6 --rows 8`（輸出 `.anim-shots/name-<id>-old.png`）。
2. 重寫 `src/names/scenes/<id>.ts`（整份重寫，`export default scene({...})`）。
3. `anim:shot` 看總覽至少三輪（`--tag r1`…），**每一輪都用 Read 打開圖親眼看**，寫一行「哪一秒、什麼問題、改了什麼」。三次笑點前後用 `--from/--to --step 0.1` 細看，確認三次長得一樣、只有結果變大。
4. 驗收：`npx tsc -b`、`npm run names:check -- <id>`（0 錯 0 注意）、`node --test tests/names.test.mjs`。不要跑 `app:build`、`npm run play`。
5. 產出：最終總覽 `npm run anim:shot -- --name <id> --tag final --width 320 --cols 6 --rows 8`（整支一張，超過 12 秒格數不夠就加 rows）。
6. 收尾：`.anim-shots/` 裡這個名字的中間產物全部刪掉，**只留** `name-<id>-old.png` 與 `name-<id>-final.png`。

## 不要做
- 不要 git add／commit／push；不要改其他名字的劇本、`shared/names.mjs`（`note` 要改就在回報裡寫新的一句，監督者來改）；不要動 `data/`；不要開 5180。
- 引擎（`src/anim/`、`src/story/scene.ts`）不要動；缺功能就在回報裡說。
- 不要引入外部網址、不要下載圖。repo-context 的留痕由監督者做。

## 回報（精簡，不超過 30 行）
1. 一句話主軸笑點＋三次各發生什麼＋反轉＋名字幾秒唸、片長。
2. 每輪一行。
3. 驗收指令的實際結果。
4. 絕對路徑：舊版總覽、最終總覽。
5. `note` 要不要改（新的一句）；需要的道具圖；你自己覺得還不夠好的地方（老實寫）。
