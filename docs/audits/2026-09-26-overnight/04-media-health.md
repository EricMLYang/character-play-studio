# 04 · 媒體檔健檢

`media/` 有 64 個檔（62 支影片、2 張圖片）。**這份報告沒有刪除或修改任何檔案，也沒有改字卡資料。**

## 檔案完整性：沒問題

- **沒有孤兒檔**：64 個檔都有被字卡的 `media` 或 `deletedMedia` 引用
- **沒有壞檔**：62 支影片 ffprobe 全部讀得到，規格完全一致，都是 1280×720、h264、24fps、AAC 48kHz 立體聲、**10.005 秒**
- 引用了但找不到檔案的有 2 個，都是**已刪除**的草稿（鳥、笑的 `deletedMedia`），屬於正常情況：刪除時移掉檔案、保留紀錄
- 沒有在用的影片：手、機各有 1 支停用的舊版；**足的 2 支影片都是停用狀態**，孩子端目前看到的是足的圖片。羊只有一張圖片。要清空間的話，可以在 Studio 刪掉停用的版本

## 響度：各支影片落差 12 dB

每支已上架影片都用 EBU R128 量整體響度（LUFS）。58 支全部停在預設音量 0.7，實際聽到的響度從 **-30.1 到 -17.7 LUFS**，落差 12.4 dB，接近「大一倍多」的聽感差異。孩子連續看幾支時，刀、畫、跳會突然很大聲，忍、跑、豬、雨則聽不太清楚。

照每支影片的響度調整音量、把目標設在 -24 LUFS（接近現在的中位數）的話，落差會縮小到 **3.1 dB**。忍、跑、豬、雨即使開到 1.0 也還是稍微小聲，因為播放器沒辦法放大超過原始音量。

### 套用前要先決定的事

`volume` 在播放器裡**同時管三件事**（`src/play/Viewer.tsx:96、155-179`）：

1. 影片本身的音量
2. 字卡上「唸這個字」按鈕的系統朗讀音量
3. 語詞按鈕的系統朗讀音量

系統朗讀的音量跟影片音軌多大聲無關。如果照上表把刀調到 0.34，刀的唸字和語詞按鈕也會變得很小聲。建議先把兩者分開：「保留影片原音」模式下，`volume` 只套用在 `<video>` 上，朗讀固定用 1（或另設一個全域朗讀音量）。這個改動很小，你同意的話我來做。

分開之後，有兩種方式套用建議音量：

- **一次寫入**：我直接把建議值寫進 `characters.json`。不過 README 規定「改變音量後須重新預覽並確認」，一次寫入等於跳過審看。
- **匯入時自動算**（長期建議）：`server/routes/media.mjs` 匯入影片時用 ffmpeg 量響度，直接把預設音量設成建議值，而不是固定 0.7。家長審看時照樣可以微調。這台 Mac 已經裝了 ffmpeg，但要考慮沒有 ffmpeg 時的退路。

## 沒做到的：發音檢查

原本想用語音辨識確認每支影片唸的是正確的字和聲調，但這台機器沒有 whisper 之類的工具。我沒有擅自安裝。如果你想做，裝好 `whisper-cpp`（`brew install whisper-cpp` 加一個中文模型，約 1.5 GB）後，這項檢查可以再跑一整晚。
