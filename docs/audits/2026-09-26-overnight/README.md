## 等你決定的事（依影響孩子的程度排序）

1. **目**的影片多一條橫線（像梯子），建議暫停並重做 → 01
2. **玩、打、王**的最後一秒切回開場或字形跑掉 → 01
   根本原因是 prompt 寫 8 秒，但影片 AI 固定產 10 秒 → 03 有兩種改模板的做法
3. 影片響度落差 12 dB，刀、畫、跳特別大聲 → 04
   要先把「影片音量」和「朗讀音量」分開，再套用建議值
4. 下一批要加哪些字 → 02（建議先加明、看、哭、男、尖、問、間、雷）
5. 小修：口、米、木的舊 `concept` 筆畫描述、4 個語詞的圖示（彈弓🪃、火星🪐、吃飽🤤、龍的語詞） → 01
