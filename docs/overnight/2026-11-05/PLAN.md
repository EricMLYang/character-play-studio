# 夜間迭代規劃：把樂園從「能玩」做到「驚艷」（2026-11-04 夜 → 11-05 05:00）

> 給一個 Opus 5.5 單一會話（**不開子代理**）照著跑一整晚。
> 目標只有一個：早上爸爸跟小孩打開，第一眼就「哇」，而且每一個「哇」都站在識字研究有證據的做法上。
> 現況與研究整理在 `docs/learning-redesign-plan.md`，工作規矩在 `AGENTS.md`，這份只寫今晚要做什麼、怎麼做、什麼時候停。

## 0. 為什麼現在覺得「簡陋」（先講清楚病因，才知道做什麼有效）

對照市面上高品質的兒童識字／自然發音 App（Khan Kids、Endless Alphabet／Reader、Teach Your Monster to Read、Duolingo ABC、Reading Eggs），
現在的樂園學習結構其實已經對（五步一圈、間隔提取、指讀、部首、詞素），差的是**體感層**：

| 他們有、我們沒有 | 現在的樣子 | 體感差在哪 |
|---|---|---|
| **一個活著的世界**：有天空、地面、遠景，場景之間有轉場 | 每個遊戲是平色背景＋emoji | 像表單，不像地方 |
| **會演的角色**：主角會眨眼、呼吸、看著你的手指、答對跳起來、答錯歪頭 | 主角是一張 PNG 站著、夥伴是 emoji | 沒有「有人陪我玩」的感覺 |
| **摸得到的東西**：拖、拉、丟，有重量、會彈、會卡進去 | 幾乎全是「點一下」 | 點一下沒有「我做了一件事」的實感 |
| **字本身會演**：字母是怪獸（Endless Alphabet），拼起來會變成那個意思 | 字是字型，只有描字時有特效 | 字還是符號，不是東西 |
| **慶祝有意義**：解鎖的是「我的」東西、看得到自己的成長 | 彩帶、星星通用 | 慶祝久了沒感覺 |
| **衰退可見**：Duolingo 的技能會「裂開」提醒複習 | 到期的字只在怪獸出題時出現 | 他不知道哪些字快忘了 |

所以今晚**不做新遊戲**，做的是把現有七個地方的體感層一次拉上來，再把「字會演」「衰退可見」「組字」三個學習機制補進去。

### 1-4 會話被壓縮之後怎麼接

## 2. 設計原則（做每一項時要回頭對照）

1. **先動體感，不動規則**：記住程度、星星、今天的路的挑字邏輯一律不改。改的是「看起來、摸起來、聽起來」。
2. **只用 CSS／SVG／Canvas／Web Audio**：沒有新圖檔要畫（`public/hero/`、`public/emoji3d/` 既有的可以用）。
   動畫只用 `transform`／`opacity`，iPad Safari 要順；`@media (prefers-reduced-motion)` 一律尊重（已有 4 處，照那個寫法）。
3. **一個共用的舞台，七個地方共用**：做出來的角色 rig、場景層、拖放手感、音效包，都放在共用檔，每個遊戲接上就有，不要七份。
4. **畫面上的字小孩讀不到**：任何新句子進 `shared/voice-lines.mjs`（或各功能的 shared 表），音檔由 `npm run voice` 做（用 `say -o`，不會出聲）。
5. **研究上沒證據的只做「好玩」的份量**：字源動畫、兒歌是加分，不佔今天的路的站。
6. **觸控優先**：所有新互動用 Pointer Events，命中區 ≥ 64px，拖放要能在 iPad 上單指完成；桌面滑鼠只是方便測試。

## 3. 要做的切片（照順序；前面是地基，後面的都站在上面）

每一項：**目標 → 做法 → 驗收 → 預估**。預估是單人、不開子代理的時間。

### 3-1 地基：舞台與角色 rig（這一項做完，其他全部跟著變好）  ⏱ 90 分
**目標** 每個畫面都在一個「地方」裡，而且有一個會動的角色陪著。
**做法**
- `src/play/Stage.tsx`＋`styles/stage.css`：三層視差背景（天空漸層＋雲／遠山＋近地面），用 CSS 變數決定**時段**（`--stage-hour` 從裝置時間算，早上暖黃、晚上深藍帶星）與**場景**（`stage="home" | "feed" | "roots" | "book" | "town" | "puzzle"`：怪獸是廚房、部首是村子、小書是房間、小鎮是草地）。純 CSS 形狀（圓、橢圓、漸層）不用圖檔。
- `src/play/Buddy.tsx`＋`styles/buddy.css`：角色 rig。用既有 `public/hero/yang/*.png` 與夥伴 emoji 當臉，外面包一個 SVG／div 骨架做：
  **呼吸**（緩慢 scaleY）、**眨眼**（隨機 3～6 秒）、**看手指**（眼睛／頭微轉向最後一次 pointer 位置，`transform: rotate` 不超過 8°）、
  **反應**：`react="cheer" | "oops" | "think" | "sleep"`（跳一下＋擠眼、歪頭＋問號泡泡、摸下巴、打呼）。所有遊戲裡「對／錯」那一下都呼叫它。
- 畫面之間加**轉場**：`src/play/PlayApp.tsx` 切畫面時舊的往下滑出、新的從上滑入（220ms），角色跟著「走過去」。
**驗收** 首頁、餵大怪獸、部首家族、小書、小鎮五個畫面都在 Stage 裡；Buddy 在每個畫面的固定位置會眨眼；答對／答錯有反應（截連拍）。測試：`tests/stage.test.mjs` 驗時段→配色的純函式。
**先接哪裡** 首頁（今天的路）跟餵大怪獸先，那是他每天第一眼。

### 3-2 摸得到：拖放手感包  ⏱ 60 分
**目標** 把「點一下」的地方換成「拿起來放進去」，有重量、會彈、卡進去會「喀」。
**做法**
- `src/play/useDrag.ts`：Pointer Events 的拖放 hook，拿起來放大 1.08＋影子、跟手、放開時**彈簧回位或吸進目標**（requestAnimationFrame 的簡單 spring，不裝套件）、吸進去 `sfx.snap()`＋目標抖一下。
- 接到三個地方：**詞語拼圖**的補字（字卡拖進 □）、**餵大怪獸**（菜拖進嘴巴——點一下也還是要能吃，六歲有時候只會點）、**部首家族找家人**（字卡拖進房子）。
- 所有按鈕統一**按下去的擠壓**（`:active { transform: scale(.94) }`＋`sfx.tap`），放在 `play.css` 的共用規則。
**驗收** 三個遊戲拖放與點擊兩種都能完成一題；放錯回彈、放對吸入；截圖拖曳中的樣子。測試：spring 純函式收斂。
**早上要人驗** iPad 實機拖的手感（Claude 只能用滑鼠）。

### 3-3 聲音設計包  ⏱ 40 分
**目標** 每個畫面有自己的「聲音身分」，答對是一段往上爬的音階而不是同一聲 ding。
**做法** `src/lib/sfx.ts` 加：`uiKit`（pick／drop／snap／nope（軟的、不嚇人）／whoosh 轉場）、`ladder(step, total)`（連對會越爬越高，錯一次重頭）、每個場景一個 2～4 音的**到站小旋律**（進怪獸廚房、進村子…）、一個很輕的**環境層**（廚房咕嚕、村子鳥叫、房間時鐘，音量 ≤ 0.04，`prefers-reduced-motion` 或 iPad 靜音鍵時不放）。
**驗收** 每個新函式在 `tests/` 驗參數（峰值 ≤ 既有 peak 上限）；Claude 聽不到——LOG 列出每一個新音效要早上戴耳機聽。

### 3-4 字會演：部首意符微動畫（研究：部首意識，中強證據）  ⏱ 70 分
**目標** 部首不只是藍色那幾筆，它會**演出自己的意思**：氵在滴水、火在閃、扌在揮手、口會張開、目會眨、心會跳、雨在下、鳥會拍翅。
**做法**
- `src/play/radicalFx.ts`：23 家各一條（`shared/radicals.mjs` 的 id → 動畫名＋粒子），`styles/radicalfx.css` 用 CSS keyframes＋少量 SVG（滴、火舌、心跳）。
- 接到三個地方：**部首家族**變身故事（水 → 氵的那一刻，氵開始滴）、**字卡 Viewer** 的「住在 💧 三點水的家」那顆標籤（hover／點一下演一次）、**筆順示範**寫到部首那幾筆時在旁邊演一小下。
- 大廳每棟房子的門牌也用同一套（房子本身會「活」：三點水的家屋簷在滴水）。
**驗收** 23 家至少 15 家有專屬動畫、其餘用通用發光；`npm run anim:check` 無關但 `npm test` 要過；截連拍。

### 3-5 蓋房子：組字工坊（部首家族的第三幕；研究：集中識字、部件意識）  ⏱ 80 分
**目標** 把「部件拼成字」做成**具體、有物理感**的事：氵（會滴水）＋ 可 → 拖在一起「喀」一聲合體成「河」，河上馬上有水流過。
魔法鍋 10/24 拿掉是因為太抽象、0 次；這次不是新入口，是部首家族每一家「找齊家人」之後的**第三幕**，而且只出**兩邊都是他看過的字**的組合（`data/parts.json`）。
**做法**
- 規則 `src/play/workshop.ts`：從 `parts.json`＋`radicals.mjs` 算出可拼的組合（部首家族的家人 × 他看過的部件），每家最多 3 題，難度：先給兩塊、再給三塊（多一塊干擾）。
- 畫面 `Workshop.tsx`：兩塊部件是**積木**（3-2 的拖放），拖近會互相吸、合體時用 `radStrokes` 的筆畫位置算部件該在字的哪一邊（左右／上下）、合體瞬間部首演它的意思（3-4）、字唸出來＋語詞。
- 紀錄：**不新增事件種類**，合體成功記成既有的 `radical`（findFamily）——它本來就是「找到牠的家」那顆星。
- 台詞進 `shared/voice-lines.mjs`：「把它們合起來！」「合體！變成」＋字、「這樣拼不起來耶，再試試」。
**驗收** 測試：組合生成、左右／上下判斷、干擾塊不會是答案；試玩 water／hand／mouth 三家各拼一題；截圖。
**早上要人驗** 小孩會不會自己發現要拖在一起。

### 3-6 衰退看得見：小鎮的「澆水」（研究：間隔提取，強證據；Duolingo 的裂開技能）  ⏱ 60 分
**目標** 快忘的字在小鎮裡**看得出來**：居民頭上出現 💧 打盹，點他就直接考一題（二選一認字），答對他醒來拉筋、變亮。
**做法**
- 純函式 `src/play/wilt.ts`：從 `progress.recall`（已有排程）算每個居民是「精神／想睡／睡著」三態（到期前一天想睡、到期睡著）。
- `Town.tsx`：三態的樣子（打呵欠動畫、Zzz 粒子）；點睡著的居民 → 用 `dishes.ts` 的出題（同一份 recall 規則）在小鎮上直接出一題，答對記既有 `recall` 事件。
- 首頁「回家」那站的提示多一句「有 N 個字想睡了，去叫醒他們！」（只在有的時候）。台詞進 voice-lines。
**驗收** 測試三態邊界；用 `npm run play`（非 `--empty`，但那是隔離的副本）看到有居民想睡；截圖。

### 3-7 字彙擴充：最熟的 60 個字各加 2 個詞（直接回應「增加有趣字彙」）  ⏱ 50 分
**目標** 詞語拼圖、小書、詞家族自動變多，而且詞要**幼兒會說、畫得出來、好玩**（恐龍蛋、火箭、電梯、冰淇淋…）。
**做法**
- 挑字：`progress.json`（**只讀**）裡 watched 次數前 60、而且現有詞 ≤ 3 個的字。
- **由 Claude 直接手寫（爸爸 11/04 已決定，不用 Studio 的 AI 補齊、不花 CLI 額度）**：每字 2 個詞＋emoji，規則照 README「語詞」：必含該字、讀音同注音（多音字特別查）、同字下 emoji 不重複、避開 `puzzles.ts` 的 `SKIP_WORDS`／`NO_PICTURE` 會擋的抽象詞。
- 寫法：**不要手改 `data/characters.json`**。寫一個一次性腳本 `scripts/words-extra.mjs` 讀 `docs/overnight/2026-11-05/words-extra.json`，用與 Studio 相同的驗證（找 `server/` 裡存語詞的那段）寫入，**單獨一個 commit**（早上併進 main 時只有這一個 commit 會碰字庫，方便處理伺服器寫入的 daily 衝突）。
- 跑 `npm run voice` 補新詞的音檔（`say -o`，不出聲，`public/voice/` 不進 git）。
**驗收** 測試：所有新詞過驗證；`npm test`（詞語拼圖的 NO_PICTURE 表若要補就補）；LOG 列出全部新詞給早上過目（**這是幼兒詞彙的判斷，爸爸要看一遍**）。

### 3-8 小書升級：有演員的小故事（研究：指讀，強證據）  ⏱ 70 分
**目標** 小書從「七個句型填空」變成一本**有角色在演的小故事**：句子唸到「他要火車」，夥伴真的跑向一列火車。
**做法**
- `shared/books.mjs` 的 `PATTERNS` 加**分級**：L1 二字（現有）、L2 主詞＋動詞＋受詞（「小老鼠要○○。」「海盜看到○○！」用 `partners.ts` 的 18 位當主詞——他們的名字已經有音檔）、L3 兩句連起來（「○○好大！他要○○。」）。只用字庫裡有的字（既有的 `patternChars` 檢查）。
- `Book.tsx`：每頁一個**舞台**（3-1 的 Stage，場景 book），主詞是 Buddy（3-1）、受詞是那個詞的 emoji 放在場景裡；唸到主詞 Buddy 揮手、唸到動詞 Buddy 走過去、唸到受詞那個東西放大跳一下。指讀問題不變。
- 指錯／指對的反應用 3-1 的 react。
**驗收** 測試：三級句型只用字庫字、同一本不重複；試玩一本 L1＋L2 混合；截圖。
**早上要人驗** 新句子的音檔接起來順不順（兩三段拼接的停頓，`sayAll` 的 gap）。

### 3-9 今日戰報：五站走完的「今天的字」卡  ⏱ 40 分
**目標** 走完今天的路，不是只放彩帶：出一張**今天的卡**——今天認識的字一個個飛進來排好、他自己寫的筆跡（小鎮存的）貼在上面、Buddy 在旁邊鼓掌、唸「今天你學會了」＋每個字。
**做法** `src/play/DayCard.tsx`：全部從紀錄算（今天台灣日期的 watched／town／recall），沒有新欄位；可以「再看一次」；家長那端（Studio 小結）**不動**。
**驗收** 用 play 走完五站看到卡；截圖。
