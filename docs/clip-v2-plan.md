# 動畫片型 v2：字是主角（2026-11-14 起）

目標：189 支識字動畫全部照新片型重做。判準從「好不好笑」改成「看完認不認得這個字」，好笑是手段。
做法：一次一支，Opus 5.5 寫、Fable 看成品驗收，爸爸看過才算定稿。不趕。

## 為什麼要改（看舊片看到的）

拍了「爬」「貓」的整支總覽對照研究，舊片型（v1）的問題：

1. **字是結尾的獎盃**。「貓」前 5 秒畫面上沒有字，第一聲「貓」唸出來時字不在場，整支只唸 3 次。
   小孩的腦力先給劇情，教的東西離劇情越遠越學不到（Fisch 的容量模型）。
2. **太滿**。10 秒 5 個笑點、4 個角色，真正的貓是畫面上最小的東西。
3. **他只能看**。問一句、停下來等他回答（Blue's Clues 的做法）跟理解與詞彙學習有正相關。
4. **沒有固定明星**。17 個主角平均輪流。有幫助的是小孩對角色的感情。
5. **筆畫從哪裡來跟字形無關**；**部件每支各演各的**，同一個「木」在不同字裡顏色、來歷都不同。

研究多半來自英文字母與學齡前節目，是方向不是保證；所以一定要量（見「還沒做的」）。

## v2 片型（劇本寫 `format: 2`）

片長 12～15 秒。

| 時間 | 做什麼 |
|---|---|
| 0–1.5s | **字從第一格就在**：國字以「空的字框」（淡淡的輪廓）停在畫面上方。明星登場、抬頭看它，唸第一聲「字」，字框跟著亮一下 |
| 1.5–7s | **一個主軸笑點做三次**（定義見下面「只有一個主軸笑點」）：同一個動作、同一個原因、同一個音效，只有結果越來越大；第三次前停一拍讓他猜。每一次都掉出一組筆畫（一個部件），飛上去填進字框 |
| 約 7s | 字框填滿：國字 `home` 到正中央放大、白光、唸第二聲「字」，停 0.8 秒以上 |
| 約 8s | 語詞那一刻：國字讓回上方，唸到的東西在畫面中間、最大 |
| 約 9–10.5s | 回馬槍＝**同一個笑點的第四次、帶一個反轉**（例：這次他以為成功了，結果還是被整），比前面都誇張；不要換成別的整法 |
| 約 10.5–13s | **問他**：畫面暗下來只剩國字亮著（`ask`），明星轉向觀眾，唸「這是什麼字？」→ **安靜等 1.5 秒以上** → 唸「字！」＋歡呼 |
| 最後 1 秒 | 回答＋歡呼之後角色、道具全部退場，畫面上只留國字（背景留著），乾乾淨淨 |

### 規則（`anim:check` 會擋的標 ✔）

- ✔ 唸的句子照順序：字、字、語詞、「這是什麼字？」、字。光唸「字」至少 3 次。
- ✔ 問句唸完到回答之間至少安靜 1.5 秒。
- ✔ 結尾至少 1 秒只有國字（沒有效果、畫面上看不到任何角色與道具）。研究的重點就是把圖拿掉、只留字。
- ✔ 片長 12～15 秒。
- ✔ `meta.gags` 只寫 1 條：主軸笑點（回馬槍是它的第四次，寫在同一條裡）。
- ✔ 卡司裡至少一個固定明星。
- **這個字講的東西要是畫面上最大、最中間的**（「貓」的貓不能比配角小）。
- 角色最多 3 個，道具最多 2 個。少就是多。
- 笑點的三拍照舊：預備 → 動作 → 反應，失敗後停 0.3～0.5 秒。被整的角色表情是「傻眼」，不是痛。

### 只有一個主軸笑點（2026-11-14 爸爸：「笑點不明顯，只排一個明顯的主軸笑點」）

好笑來自「他知道又要來了」。三種不同的整法、再疊一層猜謎，對 6 歲來說是四五個小笑點，沒有一個等得到、猜得到。

- **同一個動作、同一個原因、同一個音效**，只有結果越來越大（「貓」：每次伸手摸貓，尾巴「啪」一下把他拍飛：轉一圈 → 滾到畫面邊 → 飛上天）。
- 每次的**鏡位、站位一樣**（他都從同一邊、走到同一個地方），那一下**長得一樣、看得清楚**：有預備（尾巴抖一下）、有同一個效果（弧線＋💥），音效相同，可以一次比一次多疊一個音。
- **第三次前先停一拍**：他舉起手、看一眼、對方預備——讓小孩猜到要來了。
- **不疊第二層笑點**（猜錯的想法泡泡、別的整法、旁邊另一件事都拿掉）。開場只要一眼看懂他想做什麼。
- **回馬槍是同一個笑點的第四次，帶一個反轉**，不要換成另一種整法。

### 固定明星（從 FamilyCreation 來的，他本來就認識）

| 明星 | id | 個性（每支都一樣） |
|---|---|---|
| 豬探長 | `pig` | 很有自信，但每次都猜錯；最後還是他指出答案 |
| 浣熊花生 | `raccoon` | 熱心幫倒忙，東西都抱太多 |
| 小老鼠 | `mouse` | 動作最快、愛現，常常衝過頭 |
| 狗狗警長 | `sheriff` | 一本正經，被嚇到會跳很高 |
| 楊捷睿 | `yang` | 他自己：出主意的人，最後成功的通常是他 |

其他主角（恐龍、怪獸、機器人⋯⋯）可以當配角或「這個字講的東西」，不當說故事的人。
造型：豬探長已換成照 FamilyCreation 影片畫的新造型（綠幕姿勢表切的），其他明星進行中，見「還沒做的」第 5 點。

### 部件的顏色（`src/anim/parts.ts`）

同一個部件在每一支裡都是同一個顏色、盡量同一種來歷（木＝樹上掉下來的、氵＝水滴）。
寫劇本前先查表；表裡沒有的部件先登記再用。

## 一支的流程

1. 現有劇本複製到 `src/anim/clips-old/<字>.ts`（已經有就蓋掉，git 留著更早的版本）。
2. 用 `npm run anim -- 字` 看筆畫與部件，查 `parts.ts`。
3. 先寫一句話：誰（哪個明星）、想做什麼、那一個主軸笑點（同一個動作／原因／音效）三次怎麼越來越大、第四次的反轉是什麼。
4. 寫 `src/anim/clips/<字>.ts`（`format: 2`）。
5. `npx tsc -b && npm test && npm run anim:check -- 字`，0 錯。
6. `anim:shot` 看總覽至少三輪，每輪留一行「看到什麼、改了什麼」。
7. 新舊並排 mp4 給爸爸看。Fable 看過總覽才 commit。

## 還沒做的（依序）

1. **象形字變形**：山、羊、龜這類字，讓東西的輪廓直接流動成筆畫（引擎要加）。
2. **聲音**：音效從程式合成的嗶聲換成錄音素材、加拼好字的音樂記號；配音從 `say` 的 Meijia 換成比較自然的聲音（這台 Mac 有 Flo、Sandy、Shelley 等台灣中文語音可試），片型確定後爸爸錄正式版。
3. **量學習效果**：看完當下與隔天各問一次「哪一個是 X？」，記成一種新的紀錄（`shared/play-events.mjs`）。沒有這個，「有沒有變好」只能用猜的。
4. **讓他動手**：問句那一刻改成他點／拖最後一個部件，而不只是等。
5. **明星的新造型**（進行中）：試過從 FamilyCreation 影片直接抽格去背——全身入鏡的格太少、鞋子常被切、光線不一，放棄。
   改用 Codex 的生圖模型、拿影片截圖當參考，畫綠幕九宮格姿勢表（`assets/hero-sheets/`，做法見那裡的 README），`npm run hero:cut` 切成姿勢圖。
   - 豬探長：已換（A 表情、B 動作、C 道具與生活動作，27 個姿勢）。
   - 浣熊花生、小老鼠：姿勢表生成中。
   - 楊捷睿、狗狗警長：待定。
   注意：FamilyCreation 的影片有龍貓、變形機器人等別人的角色，也有家人的臉，**只當參考圖，不直接放進 App**。
