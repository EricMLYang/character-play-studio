# 學習路線重整規劃

> 2026-10-24 起草，等使用者決定第 5 節的幾件事才動手。
> 目標：用**更有效的方式**讓他學會認字，不是再多一個遊戲。玩法可以刪、合併、重排。
> 依據：外面識字教學法與研究的整理（見第 1 節），以及他實際怎麼用現在的樂園（第 2 節）。

---

## 1. 研究怎麼說（只列對 6 歲有證據的）

| 證據強度 | 做法 | 一句話 |
|---|---|---|
| 強 | **間隔提取**：隔一段時間，自己把字想起來 | 幼兒學新詞，隔開來練、自己回想，記得比一直重看牢 |
| 強 | **共讀時指著字讀**（print referencing） | 多項實驗證實有效、效果持續兩年；但大人不會自然這樣做，要提醒；孩子看繪本時眼睛只有 5% 落在字上 |
| 強 | **寫字** | 會寫的孩子認字較好，因為寫的時候在分析字的結構；用手寫比只用眼睛看更能幫助認字 |
| 中強 | **部首（意符）意識** | 不認得整個字也能靠部首猜意思；讀得好的孩子部首意識強 |
| 中強 | **詞素意識**：同一個字在不同詞裡 | 比聲韻覺識更能預測讀寫；一個字出現的詞越多越好學 |
| 中 | **聲旁** | 小二學新字時聲旁真的有幫助，注音反而沒有；遊戲教聲旁識字量明顯進步。但聲旁不一定準，要挑念法真的接近的 |
| 中 | **集中識字**：同一家的字一起學 | 比課文裡零散地教更容易看出組字規律 |
| 弱 | 兒歌、韻文識字；象形字源記憶 | 幼兒的對照研究少、結論不一；字源法多是成人研究 |

研究的限制：多是小樣本、小一到小四；6 歲以下的少。所以下面是「照證據的方向做」，不是保證。

## 3. 重整的原則

1. **一條路，不是一排門**：打開就是「今天的路」，4～5 站走完就結束（10～15 分鐘）。自由逛字卡、各遊戲都還在，收在路的後面。
2. **每個字都走完同一個圈**：看（故事）→ 寫（分析字形）→ 想起來（間隔提取）→ 用（在詞、在句子裡）→ 連（住哪一家）。五顆星就是這五步，不是五個遊戲。
3. **以文帶字**：學過的字要出現在他能自己讀完的句子裡，不然永遠是一張張字卡。
4. **少而深**：考同一種能力的玩法合併，省下的力氣拿去做研究說有效、但現在沒有的事（指讀、聲旁、憑記憶寫）。
5. **不丟掉他已經有的東西**：小鎮居民、夥伴、星星、寶箱全部保留；刪掉的遊戲，它記的紀錄留著。

## 4. 新的樣子

### 4-1 首頁 ＝ 今天的路

```
🏠 今天的路（首頁，打開就在這裡）
   ① 想起來   複習 2～3 個該複習的字（間隔提取）           ← 認字遊戲三合一
   ② 新朋友   1～2 個新字：看影片／動畫 → 描 → 憑記憶寫    ← 字卡流程
   ③ 牠的家   今天這幾個字住哪一家（部首／聲音／詞的家族）  ← 部首家族
   ④ 讀一讀   用今天與最近的字組成的 3～5 句小書，指著字讀  ← 新：指讀小書
   ⑤ 回家     搬進小鎮、開寶箱、今天的星星                   ← 小鎮＋夥伴

每一站做完打勾，五站走完放彩帶；中途離開明天從沒做完的那站接。
路的下面：「🎲 自己逛逛」→ 現在的字卡牆與遊戲入口（想重看「叫」的影片隨時可以）。
```

挑字的規則（`today.ts` 擴充）：
- ① 從「記住程度」排程裡挑今天到期的；沒有到期的就挑只看過一次、沒寫過的字
- ② 新字優先挑**能讓某一家湊滿**的字（集中識字），再看童書字頻
- ③ 就是①②那幾個字住的家；哪一家今天沒湊到兩個字就跳過這一站
- ④ 小書只用他看過的字（見 4-5）

### 4-2 字卡流程：加兩個小動作（研究裡最便宜、最有效的兩件事）

| 現在 | 改成 |
|---|---|
| 點開就播影片 | **看過的字先問**：字先蓋著／只露部首或影子，「你還記得這是什麼字嗎？」→ 他說出來或點一下才播。每次重看都變成一次回想。第一次看的字照舊直接播 |
| 描完就算寫過 | 描完多一步 **「遮起來，自己寫寫看」**：沒有外框，只有田字格和筆畫提示；寫不出來才回到描。小鎮的「長大一號」改成要靠這個 |
| 描字接在影片後面，常常看完就走 | 在「今天的路」②裡，描字是這一站的一部分，不是可以略過的尾巴 |

### 4-3 認字遊戲三合一：「冒險」（✅ 2026-10-24 決定：大怪獸當主場景）

餵大怪獸、跳石頭過河、小偵探考的是同一件事（聽到／看到字，自己認出來），記的也是同一份紀錄。合成**一站**。
他最喜歡怪獸、偵探也還可以，所以：

| 來源 | 留下什麼 | 拿掉什麼 |
|---|---|---|
| 🍽️ 大怪獸 | **主場景**：點菜、二選一起步、肚子量表、四種結局 | 無 |
| 🔍 小偵探 | 每輪一道**「神秘料理」**：盤子上的字一筆一筆畫出來，猜到了才上菜（練看字形） | 獨立入口 |
| 🌊 過河 | 夥伴輪流當**端菜的服務生**（「小老鼠端菜來了！」），一位夥伴一種天色；上面那條「餵了幾道、還差幾道」的路線圖 | 獨立入口、過河本身 |

一輪 5 道：2～3 道是該複習的、1 道是今天的新字、1 道神秘料理。難度照現在的 `recallLevel`（大怪獸原本永遠二選一，改成跟著他走）。

### 4-5 新增

**A. 指讀小書**（證據最強、現在完全沒有）
- 從他看過的字＋字卡語詞，用句型表組出 3～5 句：「火車開上山」「小魚在河裡」。句型表在 `shared/`，只用字庫裡的字，不夠的字先不用那個句型
- 一句一句唸，**唸到哪個字哪個字亮**；唸完一句，問一個指讀問題：「哪一個是『山』？」點對亮起來
- 畫面上給爸媽一行提示（只在家長模式顯示）：「唸之前先指著字問『這是什麼？』」
- 最後一頁「自己接一句」：貨架上的字拖進句型的空格（字火車的新家）
- 小書可以存下來重讀（`progress.books`），讀過的字算「用過」那一顆星

**B. 聲音家族**（延續部首家族的做法）
- 內容表 `shared/phonetics.mjs`：聲旁 → 念起來像的字。現有字庫湊得出的：包→抱跑、馬→媽、青→？、可→哥、每→海、巴→爸、也→他、分→粉、工→？
- 只收**念法真的接近**的（聲母韻母至少同一個），研究說不準的聲旁反而會誤導
- 故事：「包，ㄅㄠ！抱，ㄅㄠˋ！跑，ㄆㄠˇ！念起來都很像包！」找家人：「哪一個念起來像『包』？」

**C. 詞的家族**
- 「火」這一家：火車、火山、煙火、火箭。問「這幾個詞，哪一個也有火？」
- 每個字的語詞從 3 個增加到 5～6 個（Studio 的 AI 補齊可以做），詞語拼圖與小書自動變多

**D. 星星改成五步**
| 現在 | 改成 |
|---|---|
| 👀 看過 | 👀 看過 |
| ✏️ 自己描完 | ✏️ **憑記憶寫出來**（描完只算一半，顯示半顆） |
| 🍽️ 自己認出來 | 🍽️ 自己認出來（冒險） |
| 🧩 拼好一個詞 | 📖 **在詞或句子裡讀到**（拼圖或小書） |
| 🧪 魔法鍋變出來 | 🏠 **找到牠的家**（部首／聲音／詞的家族） |

已經拿到的星星不會變少：舊的魔法鍋星直接換算成「找到牠的家」。

### 4-6 Studio（家長端）
- 今日建議改成「今天的路」的預覽：明天會複習哪幾個、新字是哪幾個、湊哪一家
