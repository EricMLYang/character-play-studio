# 主角館的名字動畫

主角館（`src/play/Names.tsx`）：牆上一張一張卡片（彩色主角＋名字＋一排 parts 小圖），他點一張、把名字的字塊照順序點進格子，
每拼好一段那段的圖就跳出來（parts），拼完那個名字的動畫就演出來，最後定格亮相、蓋一張貼紙。演完點舞台會再演一次；
拼過的卡片再點有「▶ 看動畫／🧩 再拼一次」。整批重做動畫後改 `shared/names.mjs` 的 `NAME_SCENES_REDONE`，他看過舊版的卡片會標 🆕。

- 名字的資料：`shared/names.mjs` 的 `NAMES`（`{ id, text, emoji, parts, note }`）。`note` 是可以怎麼演的建議，寫好動畫後就是「演的是什麼」；
  `parts` 是名字切成幾段、每段一個圖（下面「parts」一節），**加新名字一定要寫**
- 每個名字一支動畫：`src/names/scenes/<id>.ts`，`export default scene({...})`（沒有國字的劇本，`src/story/scene.ts`）。**有檔案的名字才會上牆**
- 範本（先整份讀過再動手，套路都不一樣）：`robot`（加強版的第一支：主軸寫成函式呼叫三次、最後反轉）、`labrador`（拔河、拉破掉出一堆）、
  `dino`（變大、被小東西嚇到）、`pigsleuth`（其實在你背後）、`threepigs`（公版童話：疊羅漢）、`wolf`（公版童話：吹房子吹到自己飛走）
- 引擎怎麼寫（動作、效果、鏡頭、音效、主角、場景、自製道具圖）：`.claude/skills/char-animation/SKILL.md` 的「讓它好笑的小技巧」「引擎速查」「主角」「自製道具圖」；
  emoji、接戲以外的規矩跟 `.claude/skills/story-scenes/SKILL.md` 一樣（主角 size／站在地上的 y、白光、兒童 emoji）
- 節奏與質感的標竿：`docs/quality-leap-plan.md`、`docs/name-redo-brief.md`（加強版的標準），以及重做過的 `src/anim/clips/在.ts`、`他.ts`、`晚.ts`、`雲.ts`、`爬.ts`

## 所有權規則（每一支都要守）

### 公版人物：演本尊，但不照改編作品

- 可以演故事裡他本人的招牌事蹟與道具：孫悟空的金箍棒、筋斗雲、七十二變；大野狼吹房子；虎姑婆半夜來敲門；年獸怕鞭炮和紅色。
- **造型不照任何一部改編作品**（動畫電影、卡通、遊戲版）：白雪公主不畫成某部動畫的藍黃裙、紅髮帶；小美人魚不畫成某部動畫的紅髮綠尾巴；
  孫悟空照《西遊記》書裡的樣子（猴子、金箍、虎皮裙），不照哪一部卡通、遊戲的造型。照故事的文字描述自己畫。
- 主角的圖可以用專門畫的圖（`prop:<名字>`，`public/props/`，做法在 `char-animation` SKILL 的「自製道具圖」），比 emoji 精緻，
  也湊得出 emoji 沒有的人物（孫悟空）。名字的貼紙、parts 也可以用同一張（下面「parts」）。
- 檔頭第一行註解寫「演的是本尊：……」（`names:check` 會擋）。

### 通用的詞：演字面意思

- 名字只是「詞」，**動畫演這幾個字的字面意思**：卡車「卡」在橋下、恐龍的「恐」是被小雞嚇到、拉布拉多警長的「拉」是用力拉布袋。
- 只用現成的 3D emoji（`public/emoji3d/` 已有的）、`public/props/` 的自製圖和 `public/hero/` 的自家主角。不下載、不描任何作品的圖。
- 檔頭第一行註解寫「演的是字面意思：……」（`names:check` 會擋）。

### 兩類都一樣

- 不用任何改編作品的標誌、字體、配色組合、招牌道具、口頭禪、音樂。
- 自家主角裡有些名字跟有名的作品撞到（`hero:sheriff` 叫「拉布拉多警長」、`hero:pig` 是「豬探長」），
  用之前想清楚它像不像那部作品；拉布拉多警長的範本刻意不用 `hero:sheriff`，改用 🐕 背著 🚨。拿不準就換 emoji，並在回報裡問家長。
- 判準：**把字幕遮掉，一個人只會看到「故事裡的那個角色在做他招牌的事」或「卡車卡在橋下」，認不出是哪一部動畫、哪一部電影的畫面。**

## parts：名字切成幾段，每段一個圖（加新名字一定要寫）

拼字時，一段的最後一個字放進去，那段的圖就彈出來、唸出來（「花朵的花」）；牆上的卡片下面也先排出這一排預告會演什麼，
亮相那一頁名字下面再排一次。**為什麼**：動畫整支只唸名字，六歲看不出這段戲跟名字的關係——「花朵＋生出來＝花生」要有人講出來。

```js
{ id: 'peanut', text: '花生', emoji: '🥜', parts: [
  { chars: '花', word: '花朵', emoji: '🌻' },
  { chars: '生', word: '花生', emoji: '🥜' },
], note: '…' }

// 公版人物用專門畫的圖（public/props/wukong.png）當貼紙；parts 可以混用 prop: 與 emoji
{ id: 'wukong', text: '孫悟空', emoji: 'prop:wukong', parts: [
  { chars: '孫悟空', emoji: 'prop:wukong' },
], note: '…' }
```

- **依據是動畫實際演的東西**：先寫好（或讀過）劇本，再照它切。動畫裡「花」是花朵，就不能寫成花錢；對不上就是劇本或 parts 有一邊要改。
- `chars` 依序接起來要**剛好等於** `text`。一段可以是一個字（花）或一個詞（小豬、消防車、警長）。
  不是國字的（全形字母、標點）、沒有意思的音譯字併進相鄰那一段，每段至少要有一個要拼的國字。
  整個名字本身就是一個東西（恐龍、消防車、機器人、孫悟空）就只寫一段。
- `word`（可省略）：這幾個字在動畫裡代表的**小孩聽得懂的日常語詞**，一定要包含 `chars` 的國字（花→花朵、拉→用力拉）。
  `chars` 本身已經是詞（小豬、恐龍）就不寫。拼好時唸：有 `word` 唸「`word`的`chars`」；沒有 `word`、兩個字以上唸那個詞；
  一個字又沒有 `word` 就不再唸（剛剛唸過那個字了）。句子由 `partLine()` 產生、進 `nameLines()`，寫完跑 `npm run voice`。
- `emoji`（貼紙與 parts 都一樣）：兩種寫法——
  - 有 3D 圖的 emoji（`public/emoji3d/`，查法在 `story-scenes` SKILL 的「emoji」節；不要為了這個下載新圖）；
  - 專門畫的圖 `'prop:<名字>'`（`public/props/<名字>.png`，512×512 透明底；跟劇本裡的 `prop:` 是同一批）。孩子端牆上的卡片、拼字頁、亮相頁
    都用 `src/play/ui.tsx` 的 `emojiArt` 畫，跟 3D 圖放在同一個 1em 的框裡。
  優先用劇本裡真的出現的那個，找不到貼切的就選最接近、小孩一眼認得出來的，並在回報裡列出來給家長審。
  一個抽象的字（小、巧、神）沒有東西可畫時，用一個小孩看得懂的手勢或符號（🤏、💡、✨）。
- 圖一樣守上面的所有權規則：公版人物照故事裡的東西選（🐒、🐯、金箍棒⋯），不照改編作品的造型；通用的詞是字面的東西。拿不準就換一個比較普通的圖，並在回報裡問家長。
- `npm test`（`tests/names.test.mjs`）與 `npm run names:check` 會擋：沒有 parts、接起來不是名字、圖畫不出來（emoji 沒有 3D 圖、prop: 沒有 `public/props/` 的圖）、`word` 沒包含那幾個字。

## 品質標準（每一支都要達到）

1. **7～12 秒（2026-11-18 起加強重做，標準與派工單在 `docs/name-redo-brief.md`：一個主軸笑點做三次、角色要大、用姿勢演），一段有頭有尾的小短片**，不是一個亮相：
   ①出場（1 秒內有東西動，帶預備動作）→ ②想做一件事 → ③出包或升級（至少一次意外）→ ④笑點高峰 → ⑤反應＋定格亮相。
2. `cues` 裡**剛好一句 `say`＝名字的 `text`**（有全形字母照寫），放在 ④ 或 ⑤ 主角最大、最清楚的那一刻；其他只放音效。
3. **至少兩個角色互動**（主角＋對手／受害者／會回嘴的道具），不是一個 emoji 自己動。至少一個「**先期待、再落空**」的笑點：停一拍再爆（貓醒了左看右看……又睡了）。
4. **用滿引擎**：每支至少一次鏡頭推近（`punch`／`zoom`）、一次 `shake`、粒子（揚塵、星星、汗、煙）、一次光線或背景變化（`lights` 日夜、閃光，或 `tint`）、**5 個以上對上動作的音效**。
5. **構圖**：亮相時主角佔畫面高度 40% 以上（最後 `zoom` 1.3～1.55 倍推近，或 `scaleTo`）；背景道具 2～3 個（舞台不要空空的）；顏色跟背景對比清楚。
6. **結尾亮相值得當貼紙**：主角擺姿勢＋閃光或彩帶（`burst` ✨🎉），**停 0.8 秒以上**。演完畫面會停在最後一格、蓋貼紙，點舞台再演一次。
7. **每支不同套路**：不要都是「追→撞→星星」。節奏、場景（室內／夜晚／山上／街上／樹林／沙漠）、笑點類型都要換；寫之前看一下已有的幾支用了什麼。
8. 白光（`lights` 負值）最多 `-0.5`。emoji 只用已有 3D 圖的，不用兒童 emoji。

自問：**6 歲男孩看完會不會想再拼一次來重看？** 不會就再改。

## 寫一支

1. 讀 `NAMES` 裡那個名字的 `note`、上面的名單與所有權規則（它是公版人物還是通用的詞），寫下一句話的笑點、五拍的時間表、用哪個場景。
   名字切成哪幾段（`parts`）跟笑點一起想：每一段都要在畫面上認得出來。
2. 新增 `src/names/scenes/<id>.ts`（檔名＝名字的 id）。照範本：常數寫站位（`G = 77 − 0.42 × size`），
   一起移動的東西（車上的貨、背上的警燈）寫一個小函式照抄動作（範本 `labrador` 的 `dog()`）；同一個笑點做三次寫成函式呼叫三次（範本 `robot` 的 `dance()`）。
3. 用到的 emoji 先查有沒有 3D 圖（`story-scenes` SKILL 的「emoji」節）。
4. `npx tsc -b && npm run names:check -- <id>`：錯誤一定修；「注意」是品質標準缺了哪一項，也要補到沒有。

**注意 3D 圖跟 Apple emoji 不一樣**：🕵️ 手上本來就拿著放大鏡、🦝 只有一顆頭、⛰️ 的山頂不在正中間。
擺位置對不準時，暫時在劇本裡放幾顆小紅點（🔴 size 3）在已知座標上，拍一格（`--from 0 --to 0.01 --width 800 --cols 1 --rows 1`）量出來再拿掉。

## 看成品，至少三輪

```bash
npm run anim:shot -- --name <id> --tag r1 --width 400 --cols 6 --rows 7      # 整支每 0.25 秒一格，一張看完
npm run anim:shot -- --name <id> --from 5 --to 7 --step 0.05 --tag fine --width 300 --cols 7 --rows 6   # 笑點前後 1 秒細看
npm run anim:shot -- --name dino,wolf --tag final --width 400 --cols 6 --rows 7   # 一次好幾支；--name all 全部
```

輸出在 `.anim-shots/name-<id>-<tag>.png`，**用 Read 打開親眼看**。每一輪寫下「哪一秒、什麼問題」再改，下一輪換 tag。
最後一輪另外拍笑點前後 1 秒的細格。檢查清單：

- [ ] 遮掉字幕看得懂發生什麼事，而且**認不出是哪一部改編作品**（公版人物）、**不像任何作品的角色**（通用的詞）
- [ ] 五拍都在：出場有預備動作、有意外、有停一拍的落空、高峰、亮相停 0.8 秒以上
- [ ] 唸名字的那一刻，主角最大、最清楚
- [ ] 每一秒都有戲：沒有連續三格完全沒變的畫面
- [ ] 角色沒被畫面邊切掉、沒互相蓋住臉、頭上的符號沒疊在一起；飛出去的東西鏡頭沒有跟著跑掉（需要就自己寫 `zoom` 定住）
- [ ] 道具站在該站的地方（車在坡上、警燈在頭上，不是飄在半空）
- [ ] 亮相時主角佔畫面高度 40% 以上

Chrome 分頁在背景時動畫不會跑，驗動畫一律用 `anim:shot`。試播頁：`/anim?name=<id>`。
你聽不到聲音：名字唸的時機用 `names:check` 驗；發音（多音字：警「長」唸 ㄓㄤˇ）與音效請使用者戴耳機確認。

## 驗證與試玩

```bash
npx tsc -b && npm test && npm run names:check && npm run app:build
npm run voice       # 新名字的音檔（名字、「XX！把他的名字拼出來！」、parts 的「花朵的花」都在 shared/names.mjs 的 nameLines）
npm run play        # http://127.0.0.1:5199/ →「自己逛逛」→ 主角館（隔離資料；新增動畫檔後要重開它）
```

不要對著 5180 試玩。不要 commit 別人的改動（`data/characters.json` 常有伺服器寫入）。
