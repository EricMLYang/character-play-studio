# 識字動畫短片

孩子端播放順序：**上架影片 → 動畫 → 圖片 → 字卡動畫**。動畫是在 Gemini 影片做好之前補上的版本，
影片一上架就自動改播影片，所以**只替沒有影片的字做動畫**。

觀眾是 6 歲男孩。畫面樸素沒關係（emoji＋平面國字），但**一定要好笑**，而且每支都要不一樣。

## 流程

### 1. 挑字

```bash
npm run anim
```

列出「沒有上架影片、也沒有動畫」的字，孩子端看得到的排前面，最後列出已用過的主題／卡司／笑點。

- 使用者有指定字：先確認那個字確實沒有影片也沒有動畫（`npm run anim -- 字` 會警告），有就跳過並說明。
- 沒指定：從「孩子端看得到」的字往下挑；不夠才挑隱藏中的字（並在回報時提醒家長那幾個字孩子端還看不到）。
- 沒說幾個就做 **3 個**。
- 標「⚠ 沒有筆順資料」的字不能做。

### 2. 看筆畫怎麼分組

```bash
npm run anim -- 眼 睛
```

印出語詞、每一筆的範圍、部首筆畫 `radStrokes`。把筆畫分成 2～3 組（通常是部件，例如 果＝上面的框 [0–3]＋木 [4–7]），
每一組由故事裡的某個東西「變成」。y 往上：數值大的在上面。

### 3. 設計（先讀「設計守則」）

先寫一句話的笑點，再排時間軸。對照 `npm run anim` 最後列出的 meta，確認跟最近幾支**不同主題、不同主角、不同主要笑點**。

**一次做很多字（例如 10 個以上）**：先替每個字指定一個不重複的主題（表格裡的主題、生活場景都可以），
再分組交給子代理平行寫，每組 5～10 個字。子代理只寫 `src/anim/clips/<字>.ts`、跑 `tsc` 和 `anim:check`，
不開瀏覽器、不碰 git；全部寫完後由你重開 dev server，逐格看過再回報。

### 4. 寫檔

新增 `src/anim/clips/<字>.ts`（檔名就是那個字），`export default` 一份 `Clip`。照 `src/anim/clips/` 裡現有的檔案寫：
檔頭用兩行註解說清楚故事與唸的內容，`meta` 寫成**一行**（腳本用正規表示式讀它）。
新檔案會自動出現在孩子端、Studio 預覽、`/anim` 試播頁，不用改別的檔案。

引擎缺功能（例如需要新的效果）可以加在 `src/anim/clip.ts`／`AnimPlayer.tsx`，但要維持「畫面只由 t 決定」的純函式寫法。

### 5. 驗證

```bash
npx tsc -b && npm test
npm run anim:check -- 字1 字2   # 檢查唸字次數與時機、筆畫有沒有漏、角色 id 與主角圖、國字完成後有沒有被擋住或被鏡頭切掉、效果有沒有出界
```

`anim:check` 的「錯誤」一定要修；「注意」看情況：東西飛過字前面不到 0.5 秒、刻意從畫面外進來的效果可以留著。
唸字的「會被打斷」是用**真實音檔長度**算的（`public/voice/index.json`，dev server 開著就會自動把新劇本的句子做好；
沒有就先跑 `npm run voice`），所以這一項要認真修：把下一句往後挪，或把前一句提早。

再用 `anim:shot` 看整支成品（背景開 headless Chrome 跑真正的試播頁，不用開瀏覽器、不碰孩子的紀錄）。
**劇本用到新的 emoji（角色、swap、效果都算）後，出總覽之前先跑 `npm run emoji3d`**：孩子端預設畫 3D 圖，
還沒下載的 emoji 會先用系統 emoji 字代替，看到的不是孩子端的樣子（3D 版的朝向、顏色、留白常常不一樣）。
最後一行列出「對不到 3D 圖」的就換一個有 3D 圖的 emoji（太新的 emoji 舊 iPad 也可能顯示成方框）。

```bash
npm run anim:shot -- 字1 字2              # 整支每 0.25 秒一格的縮圖總覽，每格左上角標秒數（一支約 6 秒）
npm run anim:shot -- 字 --from 3 --to 5 --step 0.05   # 有疑問的片段細看
npm run anim:shot -- 字 --mp4             # 另外出一支 30fps 無聲 mp4（給爸爸看，或自己抽格）
npm run anim:shot -- 字 --tag before      # 檔名帶 tag，改前／改後各出一份來比（--out 可換資料夾）
npm run anim:shot -- 字 --old --tag old   # 拍重做前的舊版（src/anim/clips-old/字.ts）
npm run anim:shot -- 字 --tag r1 --width 400 --cols 6 --rows 7   # 整支 41 格塞一張，打磨時最好用
```

輸出在 `.anim-shots/`（已 .gitignore），會印出每個檔的絕對路徑，**用 Read 把 PNG 打開親眼看**。
- 先看整支的**節奏**：每個笑點前有沒有停頓、高峰有沒有停夠（至少兩三格一樣的畫面）、哪裡一格就跳過去（太趕）、哪裡好幾格都沒事（太空）、
  角色有沒有一格突然換位置或消失（硬切）、國字拼好之後角色還有沒有事做。
- 再對有疑問的片段用 `--from/--to --step 0.05` 細看。
- 新增劇本檔不用重開什麼：`anim:shot` 每次都自己起一個新的 dev server。給的字沒有劇本會直接報錯。
- 想手動在瀏覽器看某一秒，`http://localhost:5180/anim?char=<字>&t=<秒>` 還是會定格在那一秒；
  但 Chrome 分頁常是 hidden，rAF 不跑，**不要用播放來驗證**。
- 每支至少看：開場、每個笑點的高峰、筆畫組成中、國字完成、語詞那一刻、結尾。
- 檢查：角色有沒有互相重疊或被蓋住（actors 陣列順序就是繪製順序，後面的在上面）、頭上的東西有沒有懸空、
  效果有沒有被畫面邊緣切掉、國字完成後有沒有角色擋住字、結尾鏡頭推近時重要角色還在不在畫面裡、console 沒有錯誤。
- 不要點孩子端的字卡來測：播完會寫一筆觀看紀錄到 `data/progress.json`（那是孩子的真實紀錄）。真的點了要刪掉那筆。
- **你聽不到聲音**，但唸字的**時機**可以用 `anim:check` 驗（音檔長度是已知的）。回報時只需要請使用者確認**發音**對不對（多音字）與音效好不好聽。

### 5b. 看總覽 → 列問題 → 改，至少三輪（新劇本、重做舊劇本都必經）

寫完能過 `anim:check` 只是起點。**每一支都要跑至少三輪**：

1. `npm run anim:shot -- 字 --tag r1 --width 400 --cols 6 --rows 7`（每 0.25 秒一格、41 格塞一張，一眼看完整支），用 Read 打開。
2. 對著下面的「自我檢查清單」逐條看，寫下**具體**的問題：哪一秒、什麼問題（例：「6.5–7.0 只有角色站著，國字佔滿」「8.25 👋 疊在國字上」）。
3. 改劇本，下一輪 `--tag r2`、`r3`……有疑問的片段用 `--from a --to b --step 0.1`（或 0.05）細看動作有沒有連起來。
4. 每一輪在回報裡留一行「看到什麼、改了什麼」。三輪還有清單打不了勾的，繼續改。

**重做舊劇本**：先把舊檔原封不動複製到 `src/anim/clips-old/<字>.ts`（只有試播頁 `/anim?char=字&v=old` 會用，
不進孩子端、iPad 版、`anim:check`），先用 `npm run anim:shot -- 字 --old --tag old` 看舊版、列出問題再動手。
最後新舊各出一支 mp4（`--tag new --mp4`／`--old --tag old --mp4`），用 ffmpeg 左右並排給爸爸看：

```bash
ffmpeg -i 字-old.mp4 -i 字-new.mp4 -filter_complex hstack -c:v libx264 -pix_fmt yuv420p 字-old-vs-new.mp4
```

#### 自我檢查清單（對著總覽逐條打勾）

- [ ] **每一秒都有戲**：沒有連續 3 格（0.6 秒以上）整個畫面沒變的；笑點前刻意的停頓要有表情或汗（😑💦❓）。
- [ ] **國字拼好後的後半段**：拼好停 0.8～1 秒，就 `park` 讓位；角色走到畫面中間演語詞與回馬槍；結尾 `home` 回來再 pulse。
- [ ] **戲大、在中間**：主角 size 20～24；語詞那一刻主角在畫面中段（x 50～110），不是縮在角落。
- [ ] **因果看得懂**：每一個東西的出現、消失、移動，都看得出是誰對誰做的（被丟出去、被撞飛、被吸走），不能自己淡出。
- [ ] **笑點三拍**：預備（蹲、往後拉、停一下）→ 動作 → 反應（表情、汗、旁觀者偷笑），失敗後停 0.3～0.5 秒讓它落下來。
- [ ] **漸強**：第二次比第一次誇張；**回馬槍比前面都誇張**（整個人被吊上天、被雷劈成黑炭、原來山是烏龜），不是一個小符號。
- [ ] **變成筆畫那一刻是高潮**：故事裡的東西砸下去／爆開＋`camera shake`＋白光（`lights` 負值）＋音效，三個對在同一刻。
- [ ] **語詞那一刻是第二個高潮**：唸到的東西同時出現在畫面中間（床、小雲朵、旗子），配一個大動作。
- [ ] **沒有東西疊在國字上**：`fx` 的符號（👋💤❗）也算，讓位後的國字變小在上方，頭上的符號要往旁邊偏（`dx`／`dy`）。
- [ ] **邊緣**：角色、效果沒有被畫面邊切掉（衝過頭的終點留在 x 140 以內）。
- [ ] 階段 2 自動做的（步伐、落地壓扁揚塵、swap 彈一下、開場推近、閒置小動作）**沒有再手寫一次**。

### 6. 回報與 commit

回報每支的故事（一兩句、講笑點）、唸的三個詞、哪些字孩子端還看不到。

**新做的字如果是孩子端隱藏中，要問使用者要不要開放**（開放是家長的決定，不要自己開）。使用者同意後，
用 Studio「開放給孩子」背後同一支 API：`POST /api/character/visibility`，body `{"char":"字","hidden":false}`，
再讀 `data/characters.json` 確認。

使用者要 commit 時：
直接 commit 到 main，**逐一 stage 自己改的檔案**，不要 `git add -A`；`data/characters.json` 常有家長在 Studio 的變更，不是你的就不要帶進去。

## v2 片型（2026-11 起重做的劇本都用這個）

規格、時間表、固定明星、流程都在 **`docs/clip-v2-plan.md`**，動手前先讀；樣板是 `src/anim/clips/貓.ts`。
判準從「好不好笑」改成「看完認不認得這個字」：字從第一格就在、**只有一個主軸笑點**、最後停下來問他。下面「設計守則」的 10 秒結構是 v1 的，v2 照規格的時間表。

- **只有一個主軸笑點**（規格「只有一個主軸笑點」一節）：同一個動作、同一個原因、同一個音效做三次，只有結果越來越大，每次掉出一個部件；
  每次站位、鏡位一樣，那一下長得一樣（預備＋同一個效果＋同一個音效，可以一次多疊一個音）；**第三次前停一拍**讓他猜；**不疊第二層笑點**（猜謎泡泡、別的整法）；
  **回馬槍是同一個笑點的第四次、帶一個反轉**。`meta.gags` 只寫這 1 條（回馬槍寫在同一條裡）。「貓」把每一次寫成同一個函式 `swat(at, k)`，四次就長得一樣，可以照抄這個寫法。
- **`format: 2`**：劇本寫了才是 v2，沒寫的 v1 劇本畫面、檢查一格都不變。片長 12～15 秒。
- **空字框**（引擎自動）：國字從 t=0 就以淡輪廓（白底＋深色虛線邊）停在讓位的位置（畫面上方，等同 park），
  還沒拼上去的筆畫才畫輪廓、落定那一刻淡掉；拼好之前每唸一次這個字，字框亮一下（黃色）。
  builds 的筆畫會落進字框**當下**的位置與大小，起點照舊是 `from` 的角色。字框填滿後劇本自己寫 `home` 放大到正中央，之後照舊 `park`／`home`。
- **問他 `ask`**：glyph 加 `{ at, dur, do: 'ask', keep?: ['pig'], to?, amount? }`。這段時間畫面暗五成，國字回到正中央原本大小、畫在黑幕上面、輕輕晃；
  這是整支最重要的兩秒：明星走到前面、`scaleTo` 放大（「貓」是 1.55 倍）面向觀眾，安靜時做「等你回答」的動作（換 `listen` 手放耳邊、往字那邊傾、點頭），回答時換 `point` 跳起來指著字。
  明星變大沒位置時，用 `to`（國字中心）／`amount`（倍率）讓國字在 ask 時稍微偏一邊、縮一點（「貓」是 `to: { x: 96, y: 43 }, amount: 0.82`，左前方給明星）；
  `keep` 列的角色（明星）和 `top` 的角色也畫在上面。結束後國字回到原位，所以要結尾留在正中央就在 ask 裡面寫 `home`。鏡頭在 ask 時自動全景。
  明星用 `keep` 不要用 `top`：`top` 的角色整支都沒有自動質感（步伐、小動作）。
- **問句**是固定句 `FIXED_LINES.clipAsk`（「這是什麼字？」，`shared/voice-lines.mjs`）：劇本 `import { FIXED_LINES } from '../../../shared/voice-lines.mjs'`，
  寫 `{ at, say: FIXED_LINES.clipAsk }`。音檔跟其他固定句一起做（`npm run voice`）。
- **部件顏色 `src/anim/parts.ts`**：builds 的 color 寫 `partColor('豸')`；同一個部件每支同一個顏色、照表上的來歷（木＝樹上掉下來、氵＝水滴）。
  組合部件（苗＝艹＋田）可以拆兩組或合成一組。表裡沒有的部件先登記（顏色要跟表裡的分得開、在淺色背景上夠深）再用。
- **`anim:check` 對 v2 換一套錯誤**：唸的順序「字、字、語詞、這是什麼字？、字」（字至少 3 次）、問句唸完到回答之間安靜 ≥ 1.5 秒（不能有任何 cue）、
  問句要在 ask 裡、最後 1 秒只有國字（拼好、在正中央、沒有效果、**畫面上看不到任何角色與道具**——回答後全部退場、不在 ask 裡）、`meta.gags` 只有 1 條、卡司有固定明星（pig／raccoon／mouse／sheriff／yang）、片長 12～15 秒、
  結尾國字要在正中央。擋字、出界、鏡頭切字、會被打斷照舊；ask 時只有 `keep`／`top` 的角色算擋字；空字框階段角色經過**還沒填**的部分不算，**已經填上去的部件**被角色擋住 0.3 秒以上會提醒（注意）：跳高、拋高的動作要讓角色整個在字框下方。
- **明星是說故事的人，不要太小**：跟「這個字講的東西」比是「它比他大一點」（「貓」：大貓 size 34、豬探長 24）。
  想法泡泡等效果可以加 `scale`（以錨點放大，「貓」的猜錯泡泡是 1.8），泡泡裡畫的東西要一眼看得出來；放大的泡泡要用 `dx` 避開字框。
- **拍人、揮棒用 `swoosh`**（fx）：`{ at, kind: 'swoosh', actor: 'cat', target: 'pig', dx, dy, n?(半徑), sweep?(度，預設 110；150 以上從另一邊繞過來), windup?(秒), color?, width?, scale?, low?(true：弧線上下顛倒、從後下方往前甩，踢東西用) }`，
  一段弧從 actor（加 dx／dy 對到尾巴根）往 target 那一側甩過去。預設是白色細線（風切）；**要看得出是尾巴打的，就寫成跟角色同色、粗**（「貓」：`color: '#F08A2C', width: 4.2`），
  `windup: 0.2` 讓它先往反方向翹起來停一下再甩（0.25 秒一格的總覽上看得到預備）。dur 要把 windup 算進去，甩過去大約佔剩下時間的一半。
- **「啪」那一下要有重量**：打中同一刻 `camera` punch 推近到打中的位置＋shake、💥 用 `scale`，一次比一次大；被打的人傻眼停 0.4 秒以上（看得見臉）再飛出去。
- **吹人用 `blow`**（fx）：`{ at, kind: 'blow', actor: 'cat', target: 'pig', dx, dy, n?, scale? }`，一串 💨 從 actor 頭上（加 dx／dy 對到嘴巴）飛向 target，哈欠、吹氣、噴嚏的因果才看得懂。
- 片長變長，`anim:shot` 總覽用 `--rows 10`（15 秒 60 格）。

## 設計守則

### 結構（10 秒）

| 時間 | 做什麼 |
|---|---|
| 0–1.5s | 主角登場，一眼看懂他想做什麼（想法泡泡、看著某個東西） |
| 1.5–4.5s | 嘗試 → 失敗 → 再試、更誇張地失敗（漸強） |
| 4–6.5s | 笑點高峰；故事裡的東西飛過去／掉下來**變成筆畫**，國字成形 |
| 6–8s | 語詞的那一刻：唸到的東西要同時出現在畫面上 |
| 8–10s | 回馬槍：前面的笑點用意外的方式再來一次、而且**更誇張**，或一個大反轉；國字 home 回中央，最後 pulse＋cheer |

國字拼好的那一刻在正中央（佔 x 48.5–111.5、y 13.5–76.5），角色要在兩側、不能擋住。
**拼好停 0.8～1 秒後讓位**：`glyph` 加 `{ at, dur: 0.45, do: 'park' }`，國字縮到 0.55 倍移到畫面上方正中（x 63–97、y 4–39），
畫面中間空出來給角色演語詞那一刻和回馬槍；結尾 pulse 前 `{ at, dur: 0.4, do: 'home' }` 回到正中央原本的大小，這時角色要退回兩側。
沒有讓位的話，國字拼好後佔滿中央 50～60% 的片長，角色只能在角落演——這是舊劇本最大的毛病。

時間表的參考（10 秒）：國字 5.5～6.3 秒拼好 → +0.8 秒 park → 7～8 秒語詞 → 8～9 秒回馬槍 → 9.0 home → 9.45 pulse。
國字拼得越早，後面越空；拼得太晚，讓位後沒時間演。

### 唸字（cues 的 say）

固定三句：**字、字、語詞**。
- 第一聲「字」在 1–2s 內，落在一個看得到的動作上。
- 第二聲在筆畫拼好的那一刻。
- 語詞在那個東西出現或那個動作發生的那一刻。
- 語詞優先從字卡的 `words` 挑；一定要含這個字、讀音跟字卡注音一致；**語詞裡其他字不能是多音字**
  （避開 長、行、樂、重、了、得、著、數、還、都、好、為、參、落、降、度、調、傳、種、模⋯⋯），因為系統朗讀會唸錯。
- 唸字是預先做好的音檔（`server/voice.mjs` 用這台 Mac 的 `say` 做，dev server 開著會自動補新劇本的句子）。
  一次只能唸一句（新的會打斷舊的），所以下一句要等上一句唸完：`anim:check` 會用真實長度告訴你夠不夠。

### 卡司與主題（輪流換，不要老用同一種）

（專案的影片 prompt 也是同樣規定）。例如「蜘蛛人」做成「會吐絲的蜘蛛英雄」，「豬探長」做成「拿放大鏡的豬偵探」。

### 笑點套路

每支挑 2～3 個組合，**同一批不要重複主要套路**，最近 6 支裡同一個套路最多出現 2 次（看 meta）：

- **漸強失敗**：試一次不行、再試更誇張地不行（搆不到、推不動、吹不起來）
- **自作自受**：用力過猛反彈回自己身上（東西砸頭、球彈回、撞牆）
- **大小對比**：小傢伙打敗大傢伙、大怪獸被小老鼠嚇跑
- **其實一直在你後面**：大家在找，觀眾早就看到了
- **疊疊樂**：越疊越晃，最後一個壓垮
- **骨牌連鎖**：碰一個，整排倒，最後倒成字
- **失控**：魔法、超能力、機器停不下來（越喝越胖、越吹越大）
- **反轉**：可怕的東西原來很友善、帥氣的英雄其實很怕蟲
- **模仿**：跟著做，做得亂七八糟
- **變裝露餡**：偽裝成別的東西，尾巴露出來
- **身體搞笑**：打嗝、打噴嚏、臭腳丫、肚子咕嚕（6 歲男孩最愛，但一批最多一支）
- **關燈驚喜**：黑暗中只看到眼睛（`lights`＋`top`）
- **慢吞吞**：大家衝過去，樹懶最後才到
- **回馬槍**：結尾把前面的笑點再來一次（幾乎每支都要有某種結尾小反轉，但形式要換）

### 讓它好笑的小技巧

- **預備動作**：跳、衝、踢之前先 `squash` 負值（拉長蓄力），落地 `squash` 正值，再加 `puff` 揚塵。
- **停頓**：失敗後停 0.3–0.5 秒，讓 `sweat`／`bubble`（😑😅❓）出來，笑點才落得下來。
- **鏡頭**：笑點高峰用 `camera` 的 `punch` 推近主角，撞擊用 `shake`；追逐、衝刺、飛過去用 `follow` 跟拍（跟著角色走），
  蓄力時用 `zoom` 慢慢靠近，動作結束用 `zoom` `amount: 1` 退回全景。一支 1～3 次就好，**國字拼好之前要回到全景**。
- **預備動作與跟隨動作**：衝出去的 `moveTo` 加 `anticipate: 3`（先往後縮再衝）、`ease: 'in'`（越跑越快）；
  煞車、落地用 `ease: 'back'`（衝過頭彈回來）或 `'bounce'`；被彈開用 `ease: 'out'`。跑得快的角色會自動拉長、拖殘影、畫速度線。
- **擬人反應**：旁觀者的反應（偷笑 😆、翻白眼 😑、愛心 💕）常比主角更好笑。
- **筆畫要從故事裡長出來**：被丟出去的杯子、掉下來的蘋果、閃電、煙霧……不要憑空出現。
- **變化**：背景配色、筆畫顏色（可以兩個部件不同色）、筆畫組成方式（`fly`／`drop`、從哪個東西飛出來）每支都換。

## 引擎速查（src/anim/clip.ts）

播放器會**自動**加上這些質感，劇本不用寫：角色的白色貼紙描邊與軟陰影、站在地上的角色微微呼吸、快速移動時的速度線、
鏡頭推近／震動時背景的視差、每一筆落定時的小星光、國字拼好與影片結尾各一道掃光、國字的積木厚度與畫面暗角。
所以劇本專心在笑點與動作；速度線會在角色每秒移動超過約 45 單位時出現，想要「咻」的感覺就讓動作快一點。

引擎（`clip.ts` 的「自動質感」「自動取景」）另外會自動做這些，全部只由 t 決定，劇本不用寫：

| 自動行為 | 什麼時候觸發 | 寫劇本的人因此 |
|---|---|---|
| **角色放大** | 一律：size 18 以下放大三成，越大放得越少，34 以上不動；腳底高度不變。放大後國字完成時會多擋到字、或頭上的效果被畫面頂端切掉，整支就一階一階退回去 | `size` 照舊寫（以前的數字）；國字旁邊、畫面頂端要留一點空間。`actorsAt` 回傳的 size／y 已經是放大後的 |
| **自動取景** | 國字開始拼之前、劇本沒有自己寫 zoom／follow 的時段：鏡頭推近到「正在演的角色」（前後 0.4 秒內有動作或效果的），最多 1.6 倍，前後平滑、會先讓出位置給要進場的人；開場 0.2 秒先給全景；拼字前 0.6 秒退回全景。國字拼好以後，有人在演時往他那邊靠、最多 1.2 倍，國字永遠整個在畫面裡（照國字當下的位置與大小）、偏離中間不超過 12；國字 park 讓位以後最多 1.5 倍、可以偏離到 22（實際上國字在上方、角色在地上，垂直方向就佔滿了，推近通常只有 1.1～1.2 倍，所以語詞那一刻還是要靠角色 size 大、站中間）；國字拼好後的 punch／shake 前後與結尾 pulse（或最後一秒）回到全景 | **開場與失敗段不用再手寫 `zoom` 推近主角**。劇本的 zoom／follow 照樣優先（自動取景在那一段裡慢慢讓出來，退回全景後再接回）。目前沒有「這段刻意要全景」的開關（`zoom amount: 1` 不算推近，擋不住自動取景），真的需要就在回報裡提，加一個劇本欄位 |
| **走路步伐** | 會走路的角色（主角、動物、人；不含車、魚、蛇、鯊魚主角、`/drive` 姿勢）在地上水平 `moveTo`／`enter` 6 以上：上下顛＋左右擺，步數跟距離走，最多每秒 6.5 步，最後一步剛好踩在終點。有 `arc`、同時在 `hop`／`bounce`／`spin`／`drop`、`ease: bounce/elastic`、側躺、跟別人同一刻去同一點（坐車、被抱）都不加 | **不要再用一串 `hop` 假裝走路**；要「踮腳偷溜」這種特殊步伐才自己寫 hop（寫了就不會疊加） |
| **身體歪、急停甩** | 角色與車子水平移動時身體順著方向斜一點（以腳底為支點的斜切，像果凍）；停下來時上半身往前甩再晃回來：`linear`／`in` 最大，`out`／`inOut` 小一點，`back`／`bounce`／`elastic` 與緊接著下一段移動的不甩 | 想要「煞車晃一下」用 `ease: 'in'` 或 `'linear'` 衝過去就有，不用另外寫 `tilt` |
| **換姿勢彈一下** | 每個真的換了圖的 `swap`：新姿勢一出來先擠扁再彈開（約 0.26 秒） | 不用再在 swap 同一刻補 `squash`；劇本同一刻已經寫了 squash 的就不加 |
| **落地壓扁＋揚塵** | 從 `arc` 3 以上、`hop` 4 以上、`drop`、往下掉 6 以上落到地板的那一刻；高一點的才噴揚塵（畫面邊緣不噴） | 落地不用再補 `squash`＋`puff`；劇本在落地 ±0.15 秒內自己寫了 squash（或 ±0.3 秒內寫了 puff）就不重複，落地馬上又跳起來的也不加 |
| **等著時的小動作** | 角色閒著超過 1 秒：每 1.5～2.1 秒換一下重心、點一下、歪一下頭，節奏和第一下的時間由 id 決定，大家不會一起動 | 旁觀者不用再一直塞小 `tilt`／`hop` 保持畫面在動，留給真正的反應（😆、😑） |
| **唸字點頭** | 每一句 `say`：前 2.5 秒內最後有動作的角色（主角優先）點一下頭；那一刻他已經在跳、壓扁、轉圈就不加 | 不用為了「講話」補 hop |
| **殘影** | 每秒移動超過約 110 才出現，只留一個很淡的分身 | 以前兩個分身糊成一團，現在不用為了避開殘影刻意放慢 |

看成品時要注意：自動取景推近後，畫面邊緣的東西可能被切掉；國字拼好之前的笑點都會比較近、比較大。**國字拼好之後不讓位，角色就只能在兩側、比較小**（引擎不會搬動角色），所以後半段要用 glyph 的 `park`／`home`（見「設計守則」與下面的 glyph）。


舞台 160×90，地板 y = 74（`FLOOR`）。
`bg` 除了三個顏色，還要選 `scenery`（背景場景，會影響質感最多）：`hills`（小丘＋雲，預設）、`city`（城市大樓）、`ocean`（海底光束、泡泡、海草）、
`space`（星星＋行星）、`snow`（下雪＋雪丘）、`desert`（沙丘＋仙人掌）、`room`（室內：直條紋牆、窗戶、畫框、木地板）、
`night`（月亮＋星星，天空顏色要夠深）、`forest`（樹林剪影）、`track`（觀眾席＋跑道線）。故事發生在哪就選哪個，每批盡量不要都一樣。
emoji 角色站在地板上：`y ≈ 77 − 0.42 × size`（size 13 → y 71）。

- **actors**：`{ id, emoji, x, y, size, hidden?, flip?, float?(不畫影子), top?(畫在關燈黑幕上), tint?(CSS filter), pivot?('center'：旋轉以自己中心為支點) }`。陣列順序＝繪製順序。
- **moves**：`{ at, dur?, actor, do, to?, from?, arc?, amount?, times?, emoji?, ease?, anticipate?, pivot? }`
  - 會留下結果：`enter`（從 from 進到原位）、`pop`、`drop`、`vanish`、`moveTo`、`scaleTo`（倍率，會累乘）、`rotateTo`（累加）、`swap`（換 emoji 或主角姿勢）、`flip`
  - `ease`（moveTo／enter／scaleTo／rotateTo）：`inOut`（預設）、`in`（加速）、`out`（煞車）、`linear`、`back`（衝過頭彈回）、`bounce`（落地彈）、`elastic`（晃到停）
  - `anticipate`（moveTo／enter）：出發前先往反方向縮這麼遠（舞台單位，3～6）
  - 做完回原狀：`hop`（負值是往下沉）、`bounce`、`squash`（正壓扁／負拉長）、`shake`、`spin`、`tilt`、`flash`
  - 旋轉的支點預設在腳底：壓扁、翻倒都從地板發生，側躺（接近 90°）時引擎會自動把身體抬到剛好躺在地板上；倒栽蔥（180°）會繞腳底轉到原位上方，要的話自己用 `moveTo` 補位置。
  - **會滾的東西（雪球、球、輪子、陀螺、一直轉圈的角色）在 actor 加 `pivot: 'center'`**：`rotateTo`／`spin`／`tilt` 都繞自己中心原地轉，不會繞著底部甩、也不會轉進地板；邊 `moveTo` 邊 `rotateTo`（往左滾用負角度，距離 ÷ 直徑 × 360 左右）就是滾動。
  - 站著的角色偶爾要「原地空中轉一圈」：那一次的 `spin`／`rotateTo` 寫 `pivot: 'center'`（通常配 `hop`）；反過來 `pivot: 'feet'` 讓 center 的角色那一次從底部翻倒。位置、影子、步伐、擋字都不受支點影響。
  - emoji 的預設朝向依 Apple Color Emoji（很多動物、車子朝左）；要朝右就在 actor 加 `flip: true`，逐格看時確認方向對。
  - 頭上頂著東西時，主角壓扁要用 `pressStack(at, dur, amount, size, ids)`（`src/anim/helpers.ts`）讓上面那疊一起沉。
- **builds**：`{ at, dur, strokes: [筆畫編號], from: 角色 id 或 {x,y}, style?: 'fly'|'drop', color }`；每一筆落定自動有「叮」聲。
- **fx**（跟著角色頭頂，可用 dx/dy 偏移）：`burst`（n=1 是 💥，n>1 是一圈 emoji）、`dizzy`、`bubble`（想法泡泡＋emoji）、
  `sweat`、`puff`、`zzz`（emoji 可換，例如 🎵）、`pop`（頭上冒 ❗❓💡👋）、`rain`、`zap`（actor 劈閃電到 target）、`fountain`、`stink`、
  `line`（從 actor 拉線到 target 或 to：蜘蛛絲白色細線、雷射紅色粗線，用 color／width）、`beam`（飛碟往下的牽引光束，n 是底部寬度）
  、`blow`（從 actor 嘴巴往 target 或 to 吹一串 💨）、`swoosh`（以 actor 為中心往 target 那一側掃一道弧線：尾巴拍人、揮棒）；每個效果都可以加 `scale`（以錨點放大幾倍）
- **camera**：做完就回原狀 `{ at, dur, do: 'punch'|'shake', amount?, to? }`；會留下結果（維持到下一個）：
  `{ do: 'zoom', amount?(倍率，1 = 全景), to? | actor? }`、`{ do: 'follow', actor, amount? }`（跟拍）。視野永遠不會推出背景外面。
- **lights**：`{ at, dur, level }`，0 正常、1 全黑、負數是白色閃光（相機閃光燈：-0.9 再 0.3 秒回到 0）
- **glyph**：做完回原狀 `{ at, dur, do: 'wobble'|'pulse'|'shake' }`；會留下結果（國字讓位）：
  `{ at, dur, do: 'park', to?: {x,y}(國字中心，預設 {80, 21.5}), amount?(倍率，預設 0.55), ease? }` 與 `{ at, dur, do: 'home', ease? }`。
  `anim:check`：國字拼好不到 0.8 秒就 park、park 之後結尾 pulse 時還沒 home，都是**錯誤**；「擋住國字」「鏡頭切掉國字」照國字當下的位置與大小算。
  讓位後國字變小在上方（核心範圍約 x 66–94、y 7.5–35），角色可以在中間跳、站上東西，但頭上的符號、往上飛的東西要避開那一塊。
  引擎函式：`glyphPlaceAt`（中心與倍率）、`glyphBoxAt`（整個字的範圍）、`glyphCore(clip, t)`（擋字檢查的範圍）。
  v2 另有 `{ at, dur, do: 'ask', keep?, to?, amount? }`（問他：暗下來、國字到正中央亮著，見「v2 片型」）；v2 的國字一開始就在讓位的位置。
  引擎函式：`askAt`（ask 的力道 0～1）、`emptyFrameAt`（空字框的輪廓與亮度）、`isV2`。
- **自製道具圖 `prop:<名字>`**：emoji 寫 `'prop:starfruit'` 就畫 `public/props/starfruit.png`（actors、swap、fx 的 emoji 都能用）。
  圖是 512×512、長邊撐滿、底部對齊，所以 `size` 跟 emoji 一樣是道具的長邊，站在地上一樣 `y ≈ 77 − 0.42 × size`；描邊、影子、tint、flip、swap 都照常。
  引擎照每張圖量好的內容範圍（`src/anim/props.ts`）算擋字、頭頂效果的位置、影子寬度、自動取景，寬扁的捷運不會被當成大正方形。
  自動質感跟 🎁⭐ 這類道具一樣（不踩步伐、不點頭、不做小動作），`metro` 跟 🚈 一樣算車。見下面「自製道具圖」一節。
- **format**：`2` 是 v2 片型（空字框、ask、v2 的 anim:check）；部件顏色查 `src/anim/parts.ts` 的 `partColor`。
- **cues**：`{ at, say }` 或 `{ at, sfx }`；sfx：crack boing clink gulp rumble bubble poof plop cheer tap bonk whoosh slide deflate splash hic blip laser achoo
- **meta**：`{ theme, cast, gags: [...] }`，寫成一行

## 主角（固定造型的角色）

`public/hero/<主角>/<姿勢>.png` 是固定造型的角色。每個主角都有 idle、happy、dizzy、surprised，再加自己的招牌姿勢。
五個明星（豬探長、花生、小老鼠、楊捷睿、狗狗警長）已經換成 Codex 畫的綠幕姿勢表切出來的新造型，**姿勢名一模一樣**（見下面的共用表）；
機器人、車子等其他主角還是本機開源模型畫的舊貼紙，只有 6 個姿勢。

| 主角 | id | 招牌姿勢 | 適合的故事 |
|---|---|---|---|
| 楊捷睿（賽車手） | `yang` | `drive`（坐著握方向盤，坐車用）、`helmet`（戴紅色安全帽比讚） | 賽車三部曲、任何需要「小孩主角」的故事 |
| 小老鼠（紅頭巾忍者） | `mouse` | `cheese`（抱起司）、`stance`（忍者架式） | 偷吃、躲貓貓、小蝦米對大鯨魚 |
| 豬探長 | `pig` | `think`（拿放大鏡湊近看）、`doubt`（抱胸斜眼） | 辦案、找東西、其實犯人一直在背後 |
| 浣熊助手 花生 | `raccoon` | `carry`（抱一大疊箱子）、`salute`（敬禮） | 跟豬探長搭檔、幫倒忙、疊疊樂 |
| 狗狗警長 | `sheriff` | `whistle`（吹哨子）、`salute`（敬禮） | 抓壞人、維持秩序、一本正經被嚇到 |

劇本裡 `emoji: 'hero:pig/idle'` 就是他，換表情用 `swap`（`emoji: 'hero:pig/dizzy'`）。同一個主角所有姿勢同一個比例、腳底對齊，

### 五個明星共用的姿勢（`hero:<主角>/<姿勢>`，圖都朝左；要朝右用 actor 的 `flip: true`）

新圖**全部朝左**（舊貼紙有幾張是正面，所以舊劇本沒翻也看不出來）：主角在左邊、要看右邊的東西時一定要 `flip: true`，退場往反方向走要再 `flip`。

| `idle` | 平常站著、登場、等待 |
| `happy` | 開心跳起來：成功、答對、退場 |
| `laugh` | 捧腹大笑：看別人出糗、旁觀者偷笑 |
| `surprised` | 傻眼：被整那一下、看到意外的東西（笑點的「反應」拍） |
| `dizzy` | 頭暈坐地：被撞飛、滾完、摔下來以後 |
| `angry` | 叉腰生氣：被搶走東西、第三次又失敗 |
| `cry` | 大哭（眼淚噴出來）：東西壞了；要用在好笑的地方，不要真的悲傷 |
| `scared` | 抱著自己發抖：怕黑、怕大東西、聽到怪聲 |
| `smug` | 閉眼得意：以為自己成功了（回馬槍前） |
| `reach` | 伸手：想摸、想拿東西的預備拍 |
| `point` | 指斜上方「就是它！」：找到答案、ask 回答時指國字 |
| `listen` | 手放耳邊、身體前傾：問「這是什麼字？」之後等他回答（不用再另外放 👂） |
| `ponder` | 托下巴想：猜謎、第三次前停一拍 |
| `think` | 想事情。豬探長是拿放大鏡湊近看（找東西、辦案）；其他四個沒有放大鏡，`think` 跟 `ponder` 同一張 |
| `walk` | 大步走（引擎自動加步伐，劇本照樣 moveTo） |
| `sneak` | 踮腳偷溜：偷偷靠近 |
| `flat` | 被壓扁趴在地上：被拍、被壓、被踩、從高處摔下來那一下（比 squash 更誇張） |
| `wait` | 伸手掌比「等一下」：阻止別人、自己要先講（不用再另外放 ✋） |
| `back` | 背對回頭看：發現後面有東西、離開前回頭 |

| `eat` | 張大嘴吃：偷吃、吃到好吃的 |
| `dash` | 全力衝刺：追東西、衝過頭（配 follow 跟拍）。警長舊劇本的 `run` 跟它同一張 |
| `fall` | 一屁股跌坐、痛痛的：滑倒、被推倒 |
| `wave` | 揮手打招呼：登場、退場說掰掰 |
| `push` | 用力推：推大東西、推不動的預備拍 |
| `cold` | 縮成一團發抖：冷、冰、下雪 |

再加上面那張表的各自兩個招牌姿勢（豬探長的 `think`／`doubt` 也在其中）。新造型比舊貼紙高瘦，size 照舊 20～24。

**換新造型、加姿勢、加新主角的正規做法**：請生圖模型畫綠幕九宮格姿勢表，放進 `assets/hero-sheets/`，
寫 `src/anim/heroes/<主角>.cut.json`（每格的姿勢名；同一張圖要兩個名字用 `alias`），跑 `npm run hero:cut -- <主角>`，再把姿勢加進 `src/play/poses.ts`。
版面規則、prompt 範本、各格順序都在 `assets/hero-sheets/README.md`。有 `.cut.json` 的主角 `npm run hero` 會跳過，不會被舊畫風蓋回去。

還沒換的主角（舊做法）：改／新增 `src/anim/heroes/<主角>.json`（look 是長相、poses 是每個姿勢一句英文），跑 `npm run hero`
（需要 `uv tool install mflux` 與 `uv tool install 'rembg[cpu,cli]'`，Z-Image Turbo 模型第一次會下載）。
只會補缺的姿勢；想重畫某個姿勢：`npm run hero -- yang dizzy`，不滿意就改 seed 再跑。看成品：`/anim?char=楊&t=4`。

## 自製道具圖（沒有合適 emoji 的東西）

emoji 沒有、或硬湊會教錯的東西（楊桃畫成 ⭐，他會學成楊桃＝星星；📦 看起來是封著的，不是打開的禮物），**不要硬湊 emoji**：

1. 先查 `public/props/`（下表），有就寫 `emoji: 'prop:<名字>'`。
2. 沒有就先用最接近的東西頂著，在回報裡列出需要的道具（一句話描述長相、朝向、要不要附帶效果），由監督者請 Codex 畫道具表。
3. 新道具表放進 `assets/prop-sheets/`、寫 `src/anim/props/<表>.cut.json`、跑 `npm run prop:cut`（版面規則、prompt 範本在 `assets/prop-sheets/README.md`）。

| 名字 | 是什麼 | 用在 |
|---|---|---|
| `starfruit` | 一整顆楊桃（直立） | 楊 |
| `starfruit-slice` | 楊桃切片（五角星形的橫切面） | 楊（語詞那一刻切開） |
| `starfruit-tree` | 結滿楊桃的樹 | 楊 |
| `gift` | 紅盒黃緞帶、大蝴蝶結、蓋著的禮物 | 睿 |
| `gift-open` | 同一款禮物打開了（蓋子掀在左邊、裡面空的） | 睿（swap） |
| `aircon` | 白色壁掛冷氣機，下面吹出三道淺藍冷風和雪花 | 冷 |
| `metro` | 三節車廂的捷運（側面，**車頭朝右**，不用 flip；跟 🚈 一樣算車） | 捷 |
| `metro-door` | 打開的捷運雙開車門（看得到黃色扶手） | 還沒用 |
| `ice` | 大冰塊（淺藍、有裂痕） | 冷 |

注意：寬扁的道具（`metro`）size 要寫很大（長邊）：捷運 size 112 才比人高一點。原圖只有 400 像素寬，放到滿畫面會有點軟。

## 3D 角色（原型，孩子端還沒用）

`/anim` 試播頁右下角可以切換「Emoji 角色／3D 角色」（網址加 `&art=3d`）。3D 角色是 Microsoft Fluent Emoji 3D 圖（MIT 授權），
放在 `public/emoji3d/`。劇本用到新的 emoji 時跑 `npm run emoji3d` 補下載並更新 `src/anim/emoji3d.ts`。
已知問題：有些 emoji 在 3D 版朝向和 Apple 相反（例如 🚗），有些造型不一樣（🪿 是咖啡色的雁），所以還沒有換到孩子端。
