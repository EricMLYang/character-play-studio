# 故事屋的故事與場景

故事屋（`src/play/Story.tsx`）：**他讀的字，決定故事怎麼演**。一本故事一頁一頁走，走到一半停下來讓他選一個字
（選項只有字，沒有圖、不唸），選了哪個字，那個字的意思就演出來。每一種結果是一張貼紙。

- 故事的文字：`shared/stories.mjs`（檔頭有為什麼這樣設計、資料格式）
- 每一頁的戲：`src/story/scenes/<故事 id>.ts`，一段戲是一份**沒有國字**的動畫劇本（`scene({...})`，見 `src/story/scene.ts`）
- 範本：`src/story/scenes/cold.ts`（小豬好冷）。先整份讀過再動手
- 引擎怎麼寫（動作、效果、鏡頭、音效、主角、場景）：`.claude/skills/char-animation/SKILL.md` 的「讓它好笑的小技巧」「引擎速查」「主角」三節。
  **國字、builds、glyph、park、「字、字、語詞」那些都跟這裡無關**，跳過

觀眾是 6 歲男孩。他是為了看「我選的字會發生什麼事」才讀字的，所以**每一個選項的戲都要值得選**，幫不上忙的那幾個要最好笑。

## 寫一本新故事的文字

1. 只能用孩子端字庫裡的字（沒有「的、了、我、們」）。寫完跑 `node --test tests/stories.test.mjs`，會列出不在字庫的字。
   句子短（一頁 4～10 個字）、一頁一件事。避開多音字（長、樂、重、行、還、得、地、背、空、相、分、種、乾）。
2. 5～7 頁，其中 2 頁是選的頁。選的頁三種：
   - **有目標**（一個 `ok: true`）：主角有困難，一個字幫得上忙，其他的幫倒忙（好笑），演完回來再選。
   - **都可以**（全部 `ok: true`）：選哪個都往下走，結局不一樣。
   - **全部都要**（`all: true`）：每個都要選過一次，順序他決定。
3. 選項的字挑**看得到、演得出來**的（東西、動物、動作），而且意思差很多，選錯才好笑。
4. 主角從 `public/hero/` 挑，名字要是字庫裡的字（楊捷睿 yang、小豬 pig、機器人 robot、小龍 dino、超人 cape、小車 car）。
5. `emoji` 是那個結果的貼紙：要有 3D 圖（下面「emoji」）。
6. 寫完跑 `npm run voice` 做音檔（拿得到每一句的真實長度）。

## 寫每一頁的戲

一本故事一個檔，`export default` 一張表：讀的頁用頁 id，選項用「頁 id:字」（例如 `'warm:火'`）。

### 每一段戲的規矩（`npm run story:check -- <id>` 會擋）

- `cues` 裡**剛好一句 `say`**，就是那一頁的 `text`（選項是那個選項的 `text`），一字不差。其他只放音效。
  畫面下面那行字會照這一句的時間一個字一個字亮，所以**句子要落在「看得到那件事」的那一刻**（先看到火，再聽到「有火，不冷！」）。
  不能早於 0.2 秒。
- 長度：句子唸完至少再留 0.5 秒；一般 3.5～6 秒，最多 8 秒。句子多長看 `public/voice/index.json`（`story:check` 會告訴你夠不夠）。
- 舞台 160×90，地板 y=74。主角 `size: 24`，站在地上 `y = 66.9`（`77 − 0.42 × size`）。**戲要大、在中間**（x 50～110）。
- 選項的戲開頭：他剛按下那個字、聽完「給他火！」，所以**那個東西要在 1 秒內出現**（掉下來、啵一聲冒出來、有人拿進來），不要先演一段別的。
- 沒有國字，所以 `builds`、`glyph` 都不寫；`scene()` 會補。
- 白光（`lights` 負值，閃電、通電）最多 `-0.5`，再亮整個畫面一片白、對眼睛不好。

### 接戲（最容易錯，`story:check` 的「注意」會列出來，要修到沒有）

換頁時舞台直接從上一段的最後一格切到下一段的第一格：

- **下一段一開始，每個角色要站在上一段結尾的位置、同樣的大小**（同一個 `id`）。上一段結尾還在場的東西，下一段要嘛還在，要嘛上一段就先讓它離開（走掉、被吃掉、飛走）。
- **選的頁沒有自己的戲**：舞台停在上一段的最後一格等他選。所以選項的戲要從那一格接。
- **幫不上忙的選項演完要回到原本的困境**（位置、姿勢都回去，惹禍的東西要離開畫面），因為接下來可能再接任何一個選項。
- **能往下走的選項**，結尾要都接得上下一頁的開頭：最簡單是大家結尾站位一樣；不一樣的話下一頁只放「每個結局都有」的角色。
- `all: true` 的頁：三個選項誰先誰後都可能，所以每一個的開頭與結尾都要是同一個「等著的樣子」；
  想讓主角越吃越大這種累積效果，做在下一頁（讀的頁），不要做在選項裡。
- 道具用同一個 `id`、同樣的 `size`／`x`／`y` 宣告在檔案最上面共用（範本的 `fire`），就不會對不上。

### 鏡頭

故事的場景**整段都自動取景**（鏡頭一直框著正在演的角色，最多 1.6 倍），開頭結尾不會退回全景。
- 一般不用寫 `zoom`。撞擊加 `shake`，笑點高峰可以 `punch`。
- 角色放大到 `size × 倍率 > 50` 就不會被框進去（鏡頭會改框別人）。這種時候自己定住鏡頭：
  `{ at, dur: 0.3, do: 'zoom', amount: 1.02, to: { x: 80, y: 45 } }`（範本的 `hug`）。
- 放大是從腳底往上長：要讓一張大臉在正中間，腳要移到畫面下緣外面（範本 `hug`：`moveTo y: 76`、`scaleTo 2.3`）。

### emoji

孩子端畫的是 3D 圖（`public/emoji3d/`）。**只用已經有 3D 圖的 emoji**，查法：

```bash
node -e 'for (const e of process.argv.slice(1)) { const c=[...e.replace(/️/g,"")].map(x=>x.codePointAt(0).toString(16)).join("-"); console.log(e, c, require("fs").existsSync("public/emoji3d/"+c+".png") ? "有" : "沒有") }' 🔥 🪵 🧊
```

真的需要新的才跑 `npm run emoji3d`（會連 GitHub 下載、改 `src/anim/emoji3d.ts`）；3D 版常跟 Apple 的朝向、顏色不一樣，下載後一定要看成品。
不要用兒童 emoji（🧒👦👧👶）當角色；楊捷睿用 `hero:yang/…`。

### 看成品，至少三輪

```bash
npx tsc -b && npm run story:check -- <id>
npm run anim:shot -- --story <id> --tag r1 --width 400 --cols 6 --rows 4   # 每一段一張總覽（每 0.25 秒一格）
npm run anim:shot -- --story <id>/warm:火 --tag r2 --width 400 --cols 6 --rows 4   # 只拍其中一段
npm run anim:shot -- --story <id>/hug --from 2 --to 3 --step 0.05            # 細看一小段
```

輸出在 `.anim-shots/`，**用 Read 把 PNG 打開親眼看**，每一輪寫下「哪一段、哪一秒、什麼問題」再改。檢查清單：

- [ ] 沒看字幕也看得懂發生什麼事（誰、想幹嘛、結果怎樣）
- [ ] 那句話唸的時候，講的東西就在畫面上
- [ ] 每一秒都有戲：沒有連續三格完全沒變的畫面；笑點前有預備動作、後面有反應（表情、汗、星星）
- [ ] 幫不上忙的選項**比幫得上忙的更好笑**（被埋成雪人、牙齒飛出去），而且結尾回到原本的樣子
- [ ] 角色沒有被畫面邊切掉、沒有互相蓋住臉；頭上的符號沒有疊在一起
- [ ] 一換頁（上一張的最後一格 → 這一張的第一格）角色沒有瞬間移動
- [ ] 道具認得出來是什麼（3D 圖的顏色在這個背景上看得清楚）

你聽不到聲音：句子的**時機**用 `story:check` 驗；發音與音效請使用者戴耳機確認。

## 驗證與試玩

```bash
npx tsc -b && npm test && npm run story:check
npm run play        # http://127.0.0.1:5199/#/story（隔離資料，不會寫進孩子的紀錄）
```

不要對著 5180 試玩。Chrome 分頁在背景時動畫不會跑，驗動畫用 `anim:shot`，不要用播放。
