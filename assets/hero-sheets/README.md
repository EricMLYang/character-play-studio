# 主角姿勢表（綠幕九宮格）

動畫裡固定明星的姿勢圖（`public/hero/<主角>/<姿勢>.png`）都從這裡的姿勢表切出來。
這個資料夾不在 `public/`，**不會打包進 App**；App 裡只有切好的 512×512 小圖。

## 怎麼來的

- 2026-11 用 Codex 的生圖工具畫的（爸爸同意）。參考圖取自爸爸 FamilyCreation 資料夾裡孩子看熟的影片（各明星那幾支的截圖），
  所以長相是他認得的那一隻；參考圖本身不放進 repo（那批影片裡也有別人的角色與家人的臉）。
- 一張表 9 個姿勢是同一次畫的，長相、比例、上色都一致——比一張一張畫（`scripts/hero.mjs`）穩定得多。
- 檔名：`<主角>-<表>.png`，例如 `pig-A.png`（A 表情、B 動作、C 道具與生活動作）。

## 版面規則（腳本靠這些自動切，生圖時一定要做到）

- 正方形、3×3 九宮格；背景整張純綠 `#00FF00` 平塗，沒有地板、影子、漸層、文字、框線。
- 格與格之間留白：角色不能超出自己的格子、不能碰到隔壁（腳本找「整條都是綠」的空白當格線，碰到了會停下來說哪一列切不開）。
- 每格全身入鏡、同樣身高與頭身比、腳站在同一條水平線（跳起來、坐著、趴著的例外）、身體朝畫面左前方。
- 角色身上不要有綠色（反光、配件）；淚水、汗滴用淺藍沒關係，去背會留著。

## 各格的姿勢（左到右、上到下）

五個明星（豬探長、浣熊花生、小老鼠、楊捷睿、狗狗警長）的 A、B 表一模一樣；C 表 1、2 格是各自的招牌姿勢，3～9 格一樣。

| 表 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| A | `idle` 站好微笑 | `happy` 開心跳 | `laugh` 捧腹大笑 | `surprised` 傻眼 | `dizzy` 頭暈坐地 | `angry` 生氣叉腰 | `cry` 大哭 | `scared` 害怕發抖 | `smug` 得意 |
| B | `reach` 伸手 | `point` 指斜上方 | `listen` 手放耳邊等回答 | `ponder` 托下巴想 | `walk` 大步走 | `sneak` 踮腳偷溜 | `flat` 被壓扁 | `wait` 比「等一下」 | `back` 背對回頭看 |
| C | 招牌 1 | 招牌 2 | `sleep` 趴著睡 | `eat` 張嘴吃 | `dash` 衝刺 | `fall` 跌坐 | `wave` 揮手 | `push` 用力推 | `cold` 冷到發抖 |

| 明星 | 檔名 | 角色（生圖 prompt 的「角色：」那一行） | C 表招牌 1 | C 表招牌 2 |
|---|---|---|---|---|
| 豬探長 | `pig-*.png` | 圓滾滾的粉紅小豬，戴棕色格紋獵鹿帽，穿米色雙排扣風衣、白襯衫、棕色領帶、深棕色褲子與鞋子 | `think` 拿放大鏡湊近看 | `doubt` 抱胸斜眼 |

| 小老鼠 | `mouse-*.png` | 忍者小老鼠——灰色小老鼠，圓滾滾的大耳朵有粉紅色耳廓，綁紅色頭巾，穿深藍色忍者服、紅色腰帶，有一條細長的尾巴 | `cheese` 抱起司 | `stance` 忍者架式 |
| 楊捷睿 | `yang-*.png` | 約六歲的卡通小男孩，短黑髮、圓圓的大眼睛，穿紅色賽車外套（有一道黃色閃電條紋）、藍色短褲、白色球鞋，Q 版比例 | `drive` 坐著握方向盤（只有方向盤沒有車） | `helmet` 戴紅色安全帽比讚 |
| 狗狗警長 | `sheriff-*.png` | 金黃色的拉布拉多犬警長，垂耳，戴棕色牛仔警長帽，穿淺藍色襯衫、胸前金色星星警徽，脖子掛紅繩銀色哨子，兩腳站立、Q 版比例 | `whistle` 吹哨子 | `salute` 敬禮 |

- **小老鼠換了造型**：舊貼紙是沒穿衣服的調皮小老鼠；新表照爸爸影片裡的紅頭巾忍者小老鼠畫，畫風統一成跟豬探長一樣。
  劇本裡的「小老鼠」從此是忍者打扮（跟 `hero:ninja` 是不同角色）。
- **同一張圖兩個名字**（`.cut.json` 的 `alias`）：沒有放大鏡的四個明星，`think` 跟托下巴的 `ponder` 同一張，五個明星的姿勢名才一致；
  警長舊劇本用的 `run` 跟 `dash` 同一張。
- 楊捷睿的 `drive` 是坐姿＋方向盤，給 `ride(...)` 坐在車上用；圖朝左，車子朝右的話他要 `flip`。

對應寫在 `src/anim/heroes/<主角>.cut.json`。（還沒生出來的表可以設 `optional`，再用 `fallback` 先借別的姿勢頂著，劇本才不會指到不存在的圖。）

## 重切

```bash
npm run hero:cut -- pig                  # 讀這個資料夾，輸出 public/hero/pig/（整批重做，比例才一致）
npm run hero:cut -- pig --out /tmp/try   # 換新表前先輸出到別處看
```

流程：照綠色去背（邊上混到的綠扣回原色、壓掉溢色）→ 找格線切開 → 全部姿勢用同一個比例（以 `idle` 的身高佔滿畫布為準，
坐著、跳起來的不各自撐滿）→ 身體重心置中、腳底對齊底部 → 512×512。
新姿勢表放進來、在 `src/anim/heroes/<主角>.cut.json` 寫好每格的姿勢名就能切；新姿勢也要加進 `src/play/poses.ts`（測試會對）。
換表後重拍幾支用到那個主角的動畫看（`npm run anim:shot`）。

## 生圖的 prompt

每張表都是「共同前言＋九格清單」，附一張參考圖（角色的截圖）丟給生圖工具。換角色時改「角色：」那一行。

```
請用你的生圖工具（image generation）產生一張圖，存成目前資料夾的 pig-A.png，然後只回報檔案路徑與圖片尺寸。不要寫程式畫圖、不要用其他方式合成，一定要用生圖工具；解析度選最大的正方形。

圖的內容：依照我附上的參考圖，畫出同一個角色的表情姿勢表。角色：豬探長——圓滾滾的粉紅小豬，戴棕色格紋獵鹿帽，穿米色雙排扣風衣、白襯衫、棕色領帶、深棕色褲子與鞋子。

版面：一張正方形圖，3×3 九宮格，共 9 個姿勢，每格一個。格與格之間留白，角色不可以超出自己的格子，也不可以互相碰到。

每一格都要：
- 全身入鏡，從帽子頂到腳底都看得到，不能被裁切
- 同樣的身高、同樣的頭身比例、同樣的服裝與配色，跟參考圖是同一個角色
- 腳站在同一條水平線上（跳起來的那格例外）
- 身體朝向畫面左前方（四分之三側面），臉看得清楚
- 表情和動作誇張、一眼看得懂，像默劇演員

背景：整張圖是純綠色（#00FF00）平塗，沒有地板、沒有影子、沒有漸層、沒有任何道具和場景；角色身上不要有綠色反光。
（C 表這句改成：「……沒有漸層、除了該格指定的道具以外沒有其他道具和場景……」）
不要任何文字、編號、框線、對話泡泡、表情符號。
風格：跟參考圖一樣的卡通動畫質感（乾淨的深色描邊、柔和的賽璐璐上色），均勻的正面打光，色彩飽和、乾淨。

九格的內容（由左到右、由上到下）：
（接下面其中一組）
```

**A 表（表情）**
1. 站好微笑，雙手自然垂下
2. 開心跳起來，雙手舉高
3. 捧腹大笑，眼睛瞇成一條線
4. 傻眼：嘴巴張大、眼睛瞪圓、整個人僵住
5. 頭暈坐在地上，眼睛轉圈圈
6. 生氣：雙手叉腰、皺眉、鼓著臉
7. 難過大哭，眼淚噴出來
8. 害怕發抖，雙手抱著自己
9. 得意：閉眼抬下巴、一手叉腰

**B 表（動作）**
1. 一隻手往前伸出去，想摸東西
2. 一隻手指著斜上方，像在喊「就是它！」
3. 一隻手放在耳朵旁邊，身體往前傾，在等人回答
4. 托著下巴想事情
5. 大步往前走，手腳擺動
6. 踮著腳尖偷偷摸摸地走

8. 伸出手掌比「等一下」
9. 背對鏡頭回頭看

**C 表（道具與生活動作；每個角色的 1、2 格換成他的招牌動作，見上面的表）**
1. 拿著一個大放大鏡湊近看東西，一隻眼睛被放大
2. 雙手抱胸，一臉不相信地斜眼看
3. 趴在地上睡覺，閉著眼睛，很舒服的樣子
4. 張大嘴巴吃東西，兩頰鼓鼓的
5. 全力衝刺往前跑，身體前傾
6. 跌倒：一屁股坐在地上，表情痛痛的
