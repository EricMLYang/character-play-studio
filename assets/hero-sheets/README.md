# 主角姿勢表（綠幕九宮格）

動畫裡固定明星的姿勢圖（`public/hero/<主角>/<姿勢>.png`）都從這裡的姿勢表切出來。
這個資料夾不在 `public/`，**不會打包進 App**；App 裡只有切好的 512×512 小圖。

## 怎麼來的

- 2026-11 用 Codex 的生圖工具畫的（爸爸同意）。參考圖取自爸爸 FamilyCreation 資料夾裡孩子看熟的影片（各明星那幾支的截圖），
  所以長相是他認得的那一隻；參考圖本身不放進 repo（那批影片裡也有別人的角色與家人的臉）。
- 一張表 9 個姿勢是同一次畫的，長相、比例、上色都一致——比一張一張畫（`scripts/hero.mjs`）穩定得多。
- 檔名：`<主角>-<表>.png`，例如 `pig-A.png`（A 表情、B 動作、C 道具與生活動作、D 全身動作、E 吃東西與身體反應、F 身體狀況與反應；G 起是某個主角專屬的表，例如 `sheriff-G.png` 警長變老）。

## 版面規則（腳本靠這些自動切，生圖時一定要做到）

- 正方形、3×3 九宮格；背景整張純綠 `#00FF00` 平塗，沒有地板、影子、漸層、文字、框線。
- 格與格之間留白：角色不能超出自己的格子、不能碰到隔壁（腳本找「整條都是綠」的空白當格線，碰到了會停下來說哪一列切不開）。
- 每格全身入鏡、同樣身高與頭身比、腳站在同一條水平線（跳起來、坐著、趴著的例外）、身體朝畫面左前方。
- 角色身上不要有綠色（反光、配件）；淚水、汗滴用淺藍沒關係，去背會留著。

## 重切

```bash
npm run hero:cut -- pig                  # 讀這個資料夾，輸出 public/hero/pig/（整批重做，比例才一致）
npm run hero:cut -- pig --out /tmp/try   # 換新表前先輸出到別處看
```

流程：照綠色去背（邊上混到的綠扣回原色、壓掉溢色）→ 找格線切開 → 全部姿勢用同一個比例（以 `idle` 的身高佔滿畫布為準，
坐著、跳起來的不各自撐滿）→ 身體重心置中、腳底對齊底部 → 512×512。
新姿勢表放進來、在 `src/anim/heroes/<主角>.cut.json` 寫好每格的姿勢名就能切；新姿勢也要加進 `src/play/poses.ts`（測試會對）。
換表後重拍幾支用到那個主角的動畫看（`npm run anim:shot`）。

### 圖會自動壓縮

切出來的圖存檔時就減色成 **256 色的調色盤 PNG**（`scripts/png_pack.py`，libimagequant＝pngquant 的核心，Python 套件 `imagequant` 版本釘在 `scripts/py-env.mjs`）：
一張 512×512 從 200 多 KB 變 60 KB 上下，五個明星 50 MB → 17.5 MB。參數：256 色、抖色 1.0（pngquant 的預設）、調色盤帶 alpha（淚水、汗滴、半透明的邊照樣是半透明）。
2026-11-15 試過 128、64 色：淡藍的眼淚、冷風邊上開始有色階；256 色放大三倍在淺底、深底上都看不出差別，拍動畫逐格比也一樣。
同一張姿勢表重切，輸出逐 byte 相同（壓縮是決定性的），所以 git 看得出哪些圖真的變了。

舊圖、或手動放進 `public/hero/` 的圖：

```bash
npm run png:pack -- public/hero          # 整個資料夾重壓；已經是調色盤 PNG 的跳過（不會越壓越糊），.work/ 不碰
```

`npm run hero`（本機模型畫的舊主角，`scripts/hero-trim.py`）存檔時也一樣壓。

## 生圖：`npm run sheet:gen`

```bash
npm run sheet:gen -- hero sheriff G scripts/sheets/sheriff-G.txt   # 主角：<id> <表的代號> <九格清單檔>（有道具的格子加 --props）
npm run sheet:gen -- prop 9 scripts/sheets/props-9.txt             # 道具表：<第幾張> <九格清單檔>
```

- 請 Codex 的生圖工具畫，在暫存資料夾生好才搬進 `assets/hero-sheets/<id>-<代號>.png`（道具表進 `assets/prop-sheets/`）；已經有同名的圖要加 `--force` 才會蓋掉。**會連網**，送出去的只有 prompt 與參考圖。
- prompt 的前言（版面規則、綠底、畫風）**固定寫在 `scripts/sheet-gen.mjs` 裡**，每次只要給九格清單；清單放 `scripts/sheets/<id>-<代號>.txt`（一行一格、共 9 行），跟著 repo 留著，之後重生、補表才查得到當初怎麼寫。
- 角色描述（prompt 的「角色：」那一行）讀 `src/anim/heroes/<id>.cut.json` 的 `look`；參考圖用 `assets/hero-sheets/<id>-A.png`。
- 生好只是原圖：自己打開看過（九格都對、沒有互相碰到、底色乾淨），再寫進 `.cut.json` 的 `sheets`、加進 `src/play/poses.ts`，跑 `npm run hero:cut -- <id>`（可以先 `--out` 到別處看）。

**E 表（吃東西與身體反應；前言照 A、B 表）**
1. 酸到整張臉皺起來：眼睛緊閉、嘴巴嘟成一點、臉頰縮緊、肩膀聳起、全身縮著發抖
2. 辣到受不了：臉漲紅、張大嘴伸出舌頭、眼淚噴出來、一隻手在嘴邊搧風
3. 臭到捏住鼻子：一手捏鼻子、一手往前推，皺眉、身體往後仰
4. 吃得好飽：坐在地上、肚子圓滾滾、雙手摸肚子、滿足地瞇眼笑
5. 打一個大哈欠：嘴巴張得很大、眼睛瞇著、一隻手伸懶腰
6. 打噴嚏的瞬間：頭往前甩、眼睛緊閉、嘴巴張開
7. 好想吃：眼睛發亮、流口水、雙手握在胸前
8. 摀著嘴偷笑：一隻手摀嘴、眼睛彎彎、肩膀抖動
9. 累到不行：彎著腰、手撐膝蓋、舌頭吐出來喘氣、滿頭大汗

**F 表（身體狀況與反應；前言照 A、B 表）**
1. 憋尿很急：雙腿夾緊、膝蓋內彎、雙手按在肚子下方、踮著腳尖、咬牙冒汗、身體扭來扭去

4. 站著睡著：頭歪一邊、閉眼、嘴巴微張、身體搖搖晃晃快倒了
5. 舉手說我知道：一隻手高高舉直、踮腳、眼睛發亮、開心
6. 氣到跺腳：雙手握拳往下、一隻腳用力踩地、臉氣得鼓鼓的
7. 鞠躬說謝謝：彎腰九十度、雙手貼在身體兩側、微笑
8. 抱頭蹲下：蹲低、雙手抱住頭、眼睛緊閉、害怕東西掉下來
9. 滑倒的瞬間：雙腳往前滑飛起來、身體往後倒、雙手亂揮、嘴巴張大
