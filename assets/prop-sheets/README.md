# 道具表（洋紅底九宮格）

動畫裡 emoji 沒有、或硬湊會教錯的東西（楊桃、打開的禮物、三節的捷運、冷氣機…）的道具圖（`public/props/<名字>.png`）都從這裡的道具表切出來。
劇本寫 `emoji: 'prop:<名字>'`。這個資料夾不在 `public/`，**不會打包進 App**；App 裡只有切好的 512×512 小圖。

## 怎麼來的

- 2026-11 用 Codex 的生圖工具畫的，附一張主角姿勢表當畫風參考（只對齊描邊與上色，不畫出角色）。
- 新的道具表用 `npm run sheet:gen -- prop <第幾張> scripts/sheets/props-<第幾張>.txt` 生（前言固定在腳本裡、九格清單放 `scripts/sheets/`），見 `assets/hero-sheets/README.md` 的「生圖：`npm run sheet:gen`」。
- 一張表 9 個道具是同一次畫的，畫風一致。檔名：`props-<編號>.png`，對應 `src/anim/props/props-<編號>.cut.json`。

props-2 要注意：
- 檸檬三張是「同一顆被咬」的三個階段，切出來比例差不到 2%、右緣與底部對得齊，同一個 `size` 直接 `swap` 就接得上（`lemon-half` 的葉子會往右下偏一點，swap 彈一下時看不出來）。缺口在圖的**左上**：咬的人要從左邊撲過來，從右邊咬就 `flip`。
- `web` 是白線、只有很淡的灰邊，**在淺色背景上幾乎看不見**：只適合深色背景（夜晚、山洞），淺色背景要加 `tint`（例如 `brightness(.35)` 變深灰）或放在深色的東西前面。
- `plum-drink` 的玻璃杯不是真的透明：杯子上半截沒有飲料的地方畫成淡紫色（生圖把洋紅底透過玻璃的顏色畫進去了），冰塊偏粉紅；在淺色背景上看起來像有色玻璃，可以接受。

props-3 要注意：
- `wc-door` 與 `wc-open` 是同一扇門，**同一個 `size` swap，但 `wc-open` 的 x 要往左移 0.074 × size**：打開的門板往左邊凸出去，
  各自置中後門框就往右偏了 38/512 格。移過去以後門楣、右邊門框、底部對得齊（疊圖比過，差 1～2 像素）。比例一樣（兩張都是高度撐滿）。
  門的鉸鏈在左邊、門把在右邊；門上的白色圓牌（馬桶圖）在上半部正中。
- `busy` 是紅底白槓的圓牌（像「禁止進入」的標誌，沒有字），貼在門上要畫得比門牌小。
- `ladder` 細高（內容只佔畫布寬的一半多），`trampoline`、`rock` 寬扁；`net` 的網子在右上、柄往左下斜。

props-4 要注意：
- 第一張有**動物**的表，動物都朝左前方。熊三張（站／趴著睡／吼）、青蛙兩張（蹲／跳）是同一隻的幾個狀態，
  `.cut.json` 用 `together` 把它們綁成一組：**一組共用一個放大倍數**（組裡最寬或最高的那張撐滿），所以同 size、同 x 直接 swap 大小就一致。
  熊是趴著睡的那張撐滿寬，站姿只佔畫布高的 0.86；青蛙是跳的那張撐滿寬，蹲著的只佔 0.72。疊圖比過：三隻熊的頭一樣大、腳底對齊。
- `bear`、`bear-roar`、`panda`、`frog` 在引擎裡跟 🐻🐼🐸 一樣算角色（會踩步伐、閒著做小動作），`bear-sleep`、`frog-jump` 算角色但不踩步伐
  （`src/anim/clip.ts` 的 `PROP_ANIMALS`、`PROP_NO_STEPS`；之後加會走路的動物道具要登記在那裡）。

props-5 要注意：
- 螃蟹三張（`crab`／`crab-pinch`／`crab-walk`）、烏龜兩張（`turtle`／`turtle-shell`）各用 `together` 綁成一組，同一個比例。
  螃蟹是伸長螯的 `crab-pinch` 撐滿寬，`crab` 只佔畫布寬的 0.77、`crab-walk` 0.81；烏龜是 `turtle` 撐滿寬。
- **`crab-pinch` 跟 `crab` 同 size swap，x 要往左移 0.074 × size**（跟廁所門一樣的道理：左螯往左伸出去，各自置中後身體就往右偏了 38/512 格）。
  移過去以後眼睛、殼、八隻腳、右螯都對得齊（疊圖比過，差 1 像素）。夾緊的左螯尖端在（照 `crab` 的 x、y 算）x − 0.52 × size、y + 0.14 × size：要夾哪裡，就把 `crab` 擺在那個點的右邊 0.52 × size。
- `crab-walk` 跟 `crab` 同 size、同 x swap 就好：身體只往右偏 10/512、往上 3/512，整隻歪著本來就對不準，swap 彈一下看不出來。
- **`turtle-shell` 跟 `turtle` 同 size swap，x 要往右移約 0.074 × size**：烏龜的殼在圖的右半邊，縮進去的殼是置中的；移過去以後殼頂、殼的寬度對得齊（疊圖比過），
  只是縮殼的那張整個殼落到地上（伸出腳時殼是撐高的），看起來就是「腳縮進去、殼掉下來」。
- 螃蟹、烏龜、猴子在引擎裡跟 🦀🐢🐒 一樣算角色：`crab`、`crab-walk`、`turtle`、`monkey` 會踩步伐；`crab-pinch`、`turtle-shell`、`monkey-hang` 算角色但不踩步伐。
- `snowball` 白色帶淡藍陰影與深色描邊，在雪地背景（`scenery: 'snow'`）上也看得出輪廓。`banana` 寬扁，size 寫長邊。

props-6 要注意：
- 山羊三張（`goat`／`goat-butt`／`goat-rear`）、蜜蜂兩張（`bee`／`bee-sting`）各用 `together` 綁成一組，同一個比例。
  山羊是站起來的 `goat-rear` 撐滿高、低頭的 `goat-butt` 撐滿寬（0.91），`goat` 只佔畫布寬的 0.77、高的 0.83：size 要寫大一點（「羊」用 44，看起來跟 size 36 的 🐐 一樣大）。
- **三張山羊對齊的是屁股與尾巴**（疊圖比過，差 2～4 像素）：`goat-butt` 跟 `goat` 同 size swap，**x 要往左移 0.07 × size**（頭往前伸出去）；
  `goat-rear` **x 要往右移 0.074 × size**（站起來身體變窄、置中就往左偏了）。swap 同一刻 `moveTo` dur 0.01。
- `goat` 是四分之三臉，**兩支角一左一右都看得到**：照 `goat` 的 x、y（size 44）算，左角中段在 x − 6.5、y − 13.8，右角中段在 x + 0.3、y − 13（換別的 size 就照比例）。
- `goat-butt` 的角是往上往後彎的（不是朝前），頂人時碰到對方的是額頭與角根：照 `goat-butt` 畫出來的 x 算，在 x − 0.32 × size、y + 0.1 × size（size 44 → x − 14、y + 4.5）。
- `bee-sting` 跟 `bee` 同 size、同 x swap 就好（身體差 2～3 像素）；尾針朝左下。蝴蝶、蜜蜂在引擎裡跟 🦋🐝 一樣算角色，在空中飛要在 actor 加 `float`。
  山羊算會走的動物（`goat-rear` 不踩步伐），毛毛蟲跟 🐛 一樣算角色但不踩步伐；`chrysalis`（樹枝在最上面、蛹往下垂）、`lilypad`（寬扁）是道具。

props-7 要注意：
- **第 3～5 格實際畫成包子，不是餃子**：prompt 要的是「摺邊清楚的餃子」，生出來是頂上打摺、圓胖的包子，所以照實命名 `bao`／`bao-plate`／`bao-pot`。
  要餃子（半月形、邊上一排摺）得另外再生一張，prompt 要寫清楚「半月形、不是圓的包子」。
- `tree` 與 `apple-tree` 用 `together` 綁成一組，同一個比例：同 size、同 x 直接 swap，樹幹、底部、左右寬度都對得齊（疊圖比過，蘋果樹的樹冠頂只低 5/512）。
  都是一般道具（不做小動作）。
- `bao-plate`、`bao-pot`、`hotpot` 上的熱氣原本是淡粉白色的半透明線條，去背時把混進去的洋紅扣掉，留下來變成**淡灰白色**的線條，
  淺色、深色背景上都看得見（像 props-1 冷氣的冷風）。
- `water` 跟 `plum-drink` 一樣：玻璃杯上半截沒有水的地方畫成淡紫色（洋紅透過玻璃的顏色），在淺色背景上像有色玻璃，可以接受。

props-8 要注意：
- 這次 prompt 寫明「半月形、不是圓的包子、頂上沒有打結」，第 1～5 格畫出來就是台灣的水餃（彎的那邊一整排摺）。
- `dumpling` 與 `dumpling-bite` 用 `together` 綁成一組，同一個比例（兩張都是寬撐滿）：同 size swap，底部、頂端的摺邊對得齊；
  疊圖比過，`dumpling-bite` 整顆往右偏 7/512，要對得更準就把 x 往左移 0.014 × size（swap 彈一下時看不出來，可以不移）。
  咬掉的缺口在**右下**（露出綠色和粉色的餡）：咬的人要從右邊來，從左邊咬就 `flip`。`dumpling-bite` 上面多兩道熱氣，所以圖比較高。
- `dumpling-bite`、`dumpling-plate`、`dumpling-pot` 上的熱氣跟 props-7 一樣，去背後留下來是**淡紫白色**的線條，淺色、深色背景上都看得見。
- `flour` 撒出來的白色麵粉堆完整留著（沒有被去背吃掉，邊上還有幾顆小粉粒），但**白色麵粉在淺色背景上對比低**：要讓人看清楚就放在深色背景或深色的東西前面。
- `brain` 是粉紅色（不是洋紅），去背沒有吃到，皺摺、描邊都完整。

props-9 要注意（用 `npm run sheet:gen -- prop 9 scripts/sheets/props-9.txt` 生的，九格清單就在那個檔）：
- `turtle-old` 是 props-5 `turtle` 的「很老」版，**不同張表，不能用 `together` 綁**：兩張都是寬撐滿（長邊＝寬），同 size swap 寬度一樣；
  老烏龜的頭比較低、身體比較高（白鬍子垂到地上），swap 時腳底對齊、整隻差不多大，彈一下看不出跳。眼鏡的鏡片原本帶一點淡紫，去背後前面那片鏡片變透明（看得到後面），
  鏡框、反光、白眉毛、白鬍子都完整，沒有洋紅殘留。
- `cake`／`cake-halves`、`meat`／`bone`、`watermelon`／`watermelon-half` 各用 `together` 綁成一組，同 size swap。
  `cake-halves` 是同一格裡的兩半（中間有縫），切成一張圖，不是兩張。
- `rooster` 跟 `turtle-old` 一樣算動物（`src/anim/clip.ts` 的 `PROP_ANIMALS`），走過去踩步伐。

props-10 要注意（用 `npm run sheet:gen -- prop 10 scripts/sheets/props-10.txt` 生的，九格清單就在那個檔）：
- `panda-daze`／`panda-wave` 用 `together` 綁成一組，同 size、同 x swap（揮手那張舉起的手往左凸，撐滿寬的是它；身體、腳底對得齊）。
  跟 props-4 的 `panda`（啃竹子）不同張表，三張都是高撐滿，size 一樣時身體差不多大。三張在引擎裡都跟 🐼 一樣算動物。
- `rooster-sleep` 是 props-9 `rooster` 的「打瞌睡」版，**不同張表，不能用 `together` 綁**：兩張都是長邊撐滿（`rooster` 高撐滿 0.92、`rooster-sleep` 寬撐滿 0.92），
  並排比過：雞冠、身體、尾巴、腳差不多大（差不到 5%），同 size swap 腳底對齊；睡著的身體偏右一點，要對得更準 x 往右移約 0.03 × size。算動物（跟 🐓 一樣）。
- `beetle` 跟 🪲 一樣算動物（會踩步伐）。`bump`、`feather`、`book-ajar`、`gong`、`lotus-leaf` 是道具。
- 去背逐張看過（淺色、深灰底各看一次）：白羽毛的羽片與灰描邊完整、熊貓的白毛沒有被吃掉、書縫的黃光邊緣淡淡地漸到透明，九張都沒有洋紅殘留。

props-11 要注意（九格清單在 `scripts/sheets/props-11.txt`）：
- 第一張有**人**的表：姑姑六張（`aunt`／`aunt-run`／`aunt-kiss`／`aunt-cake`／`aunt-laugh`／`aunt-shock`）用 `together` 綁成一組，同一個比例、同 size 直接 swap。
  撐滿的是第二列（捧蛋糕、大笑、嚇一跳，高 0.92）；第一列三張（站好、跑、親）畫得小一點，高只有 0.88（跑的 0.86），
  並排比過：頭的大小一樣，差在第二列的捲髮蓬一點，swap 彈一下時看不出來。全部朝左前方，要面向右邊就 `flip`。
- 姑姑在引擎裡跟 🧍 一樣算**人**（`src/anim/clip.ts` 的 `PROP_PEOPLE`：走過去踩步伐、閒著換重心、唸字時點頭），`aunt-kiss` 彎著腰不踩步伐。
- `aunt-kiss` 嘟起來的嘴在圖的 u 0.35、v 0.37：照 x、y（站在地上）算在 x − 0.15 × size、y − 0.13 × size，親誰就把嘴對到那裡。
- `kiss-mark` 是鮮紅的唇印（寬扁），淺色背景上很醒目；貼在角色臉上用 `float`，跟著角色一起 `moveTo`。
- 去背逐張看過（淺色、深灰底各看一次）：天藍洋裝的白圓點、白鞋、紅唇、紅唇印、紙箱的淺色內側、灌木叢的亮綠葉子都完整，九張都沒有洋紅殘留（逐像素數過，0 個洋紅像素）。
  原圖的姑姑沒有畫出明顯的珍珠耳環。

## 版面規則（腳本靠這些自動切，生圖時一定要做到）

- 正方形、3×3 九宮格；背景整張純洋紅 `#FF00FF` 平塗，沒有地板、影子、漸層、文字、框線。
  （為什麼不用綠幕：道具常有綠色——楊桃、樹葉。換背景色寫在 `.cut.json` 的 `key`；要是「通道不是全滿就是全空」的純色，例如 `#00FF00`、`#FF00FF`、`#00FFFF`。）
- 道具身上不要有洋紅、桃紅、粉紅（會被當背景吃掉、或邊上變色）。淺藍半透明的冷風、冰塊、白色雪花不是洋紅，會留著。
- 格與格之間留白：道具不能超出自己的格子、不能碰到隔壁（腳本找「整條都是背景」的空白當格線，碰到了會停下來說哪一列切不開）。
- 每格一個道具、置中、盡量畫大。**寬扁的東西（整列火車、長椅）在九宮格裡會很小**：要放很大的（例如捷運要橫跨大半個畫面），單獨生一張（`grid: [1, 1]`）。
- 有方向的東西（車子、動物形狀的道具）在 prompt 裡寫清楚朝哪邊；切圖不會自動翻，要翻就在 `.cut.json` 的 `flip` 列名字。

## 切法（`npm run prop:cut`）

```bash
npm run prop:cut                          # 照 src/anim/props/*.cut.json 重切全部，並重新產生 src/anim/props.ts
npm run prop:cut -- props-1               # 只切這一張
npm run prop:cut -- props-2 --out /tmp/try   # 新表先輸出到別處看（不進 public/、不改 props.ts）
```

流程（`scripts/prop-cut.py`，去背與切格跟主角姿勢表共用 `scripts/sheet_cut.py`）：
照背景色去背（半透明的邊把混進去的洋紅扣回原色、壓掉溢色）→ 找格線切開 → 清掉零星雜點與生圖邊框的淡色雜訊 →
**每個道具各自裁到內容、長邊撐滿**（跟主角「整套同一個比例」不同）→ 水平置中、底部對齊、四周留 4% → 512×512 透明底。
最後量每張圖的內容範圍寫進 `src/anim/props.ts`（引擎算擋字、頭頂、影子用；`npm test` 會檢查圖、範圍表、設定三邊對得上）。
放大超過 1.6 倍（原圖太小）會提醒「會糊」。

**圖會自動壓縮**：存檔時減色成 256 色的調色盤 PNG（`scripts/png_pack.py`，跟主角圖同一套，參數與理由見 `assets/hero-sheets/README.md`「圖會自動壓縮」），
一張 200 KB 上下 → 60 KB 上下，72 張 13 MB → 5 MB。半透明的玻璃、冷風、熱氣都還在（放大三倍比過）。同一張表重切，輸出逐 byte 相同。
範圍表量的是壓過的圖（實際顯示的那張）：比壓之前少數幾張的邊差 1/512（例如 `mirror`、`starfruit-slice`），看不出來。
手動放進 `public/props/` 的圖用 `npm run png:pack -- public/props` 補壓（壓過的跳過）。

`.cut.json` 的欄位：`file`（檔名）、`key`（背景色，預設 `#FF00FF`）、`grid`（[欄, 列]，預設 [3, 3]）、
`props`（照左到右、上到下每格的名字，`null` 跳過）、`flip`（要左右翻的名字）、`speck`（比這小的零星色塊當雜點清掉，預設 40 像素）、
`together`（同一隻動物的幾個狀態要能 swap：`[["bear", "bear-sleep", "bear-roar"]]`，一組共用一個放大倍數，組裡最大的那張撐滿）。
名字不能跟別張表重複；設定裡拿掉的道具，重切時會從 `public/props/` 清掉。

1. 寫 prompt（下面的範本，改九格清單），請生圖模型畫，存成 `assets/prop-sheets/props-<下一個編號>.png`。
