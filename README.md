# 字字樂園 · Character Play Studio

給 6 歲兒子的識字影片產線 + 播放器。跑在你自己的 MacBook 上，不需要部署。觀看本機影片可離線；AI prompt 生成透過已安裝並登入的 Claude Code、Codex 或 Google agy CLI，需要網路與對應帳號額度。

```bash
npm install
npm run dev        # → http://localhost:5180
```

- **`/`** 播放器：找字、看影片或圖片、自動記錄觀看次數
- **`/studio`** 製作端：生成 prompt、匯入與上架素材、回饋。播放器右上角的 **👪 家長** 要**長按一秒**才會進來，孩子點一下不會誤入

---

## 每天的流程（大概 5 分鐘）

1. 開 `/studio`，在「今日建議」按 **⚡ 一鍵產生今天 3 支**，三個字的 prompt 會在背景依序產生；可以先去忙別的，回來看結果清單。已經有最新 prompt 的字會標 ✓ 並自動跳過，只補還缺的
2. 按建議清單或字庫的字，確認內容後按 **一鍵複製 Prompt**，看到「已複製 ✓」即可貼到你訂閱的影片 AI。想單獨重做某一個字，仍可選 **生成工具**、填模型與「這次想怎麼拍」，按 **換個創意，重新生成**
3. 實際送出 AI 後按 **已送出 AI，記 1 支**，保存這次 prompt 與製作紀錄
4. 影片下載後，在「這次匯入對應的製作紀錄」選那次製作，再拖進虛線框（也可選擇檔案）
5. 檔案自動改名入庫，先留在 **待確認**。先選發音方式、調音量，再按 **播放預覽** 並看到結尾；勾選字形／發音／音量三項確認後，按 **確認上架，使用此版本**。按鈕下方會提示目前缺哪一步；不必重新生成 prompt 或重新上傳。
6. 開 `/`，搜尋或直接點字卡看影片；有已上架影片的字排在最前面

> 一鍵批次用當下選的生成工具，一次跑一個字（CLI 本來就互斥）；單一個字失敗不會中斷其他字，錯誤會留在結果清單。進行中可按 **停止**，已完成的 prompt 會保留。批次跑的時候手動生成會先停用。
>
> 每日建議清單以台灣日期固定，完成不會補位；隔天重新挑選。複製不扣額度，實際送出才記錄，上限每日 3 支，同字重做也算一支。這是手動額度紀錄，不會連線查詢 AI 訂閱。已送出尚未匯入的紀錄會跨日保留。

AI 沒有產出可用結果時，按待匯入紀錄旁的 **沒有可用影片**，保留已用額度與 prompt，讓該字重新等待製作。

> 已有的外部影片或圖片可以選「未連結 prompt」直接匯入，不佔當日額度。圖片不會被當成影片任務完成。上架後重新整理播放器，即可取得新版素材。

新增字：左側底部按 **＋ 加一個字（可用 AI 補齊）**，輸入國字後按 **AI 補齊注音、圖示與語詞**，查看注音、英文意思、emoji 與語詞建議及字卡預覽，再按 **加入字庫**。也可以只加入國字，之後再補。AI 只填空白欄位，不會直接儲存；多音字請確認是否符合你要教的意思。動畫概念可以自行填寫，或留給影片 AI 設計；影片生成也會補上缺少的字卡資料與概念。

編輯字：選取字卡後按 **編輯字卡資料／刪除**，可修改注音、圖示、字義、語詞和動畫概念，或使用相同的 AI 補齊功能。

**語詞**最多四個、用「、」分隔，寫成「詞＋一個圖示」，例如 `生日🎂、日出🌅、日記📔`。圖示可以省略，但有圖示孩子還不會讀字就先看得懂。孩子端會顯示並唸出來，把字放回他已經會說的話裡。現有的字都各有三個詞，同一個字底下的圖示不重複。

每個詞都必須含這個字（不含的話存不進去，因為孩子看不出關聯），讀音也要跟你填的注音一致——多音字特別要檢查，例如教「長」ㄓㄤˇ就不能配讀ㄔㄤˊ的詞。隨時可以改或清空。改了字義、讀音或概念後，舊影片 prompt 會標示需更新，原有影片及創意版本仍保留。國字本身是字卡識別，若加錯字請刪除後另加正確的字。

刪除字：編輯表單按 **刪除這個字** 並確認，字卡會移到左側 **已刪除的字**，不再出現在孩子端或今日建議。影片、觀看紀錄與製作額度紀錄保留；可按 **還原** 找回，還原後先在孩子端隱藏，確認後再開放。

新加的字**預設不出現在孩子端**（列表標「孩子端隱藏」）。注音、字義與素材確認好之後，在右邊字頭旁按 **開放給孩子**，它才會進入播放器字庫；也可以隨時再 **先收起來**。

## 預覽與發音

- **保留影片原音**：播放原始聲音，可降低該版本音量。
- **系統朗讀（影片靜音）**：關閉影片原音，由這台 Mac 的中文語音隨播放進度朗讀；暫停時也停止朗讀。優先使用 `zh-TW` 聲音，請先試聽確認。
- 改變發音或音量後須重新預覽並確認。音量是每支素材的播放設定，尚未做音訊檔的自動響度正規化。
- 同字同類型只使用一個已上架版本；切換版本會保留並停用舊版。也可按 **暫停使用**，播放器會改用已上架圖片或字卡。
- 清理重複素材：在「影片／圖片」找到 **已停用** 或 **待確認** 的版本，按 **刪除影片／刪除圖片**，核對檔名後按 **確認永久刪除**。實際檔案會從電腦移除，無法還原；使用中的版本須先停用。其他版本、觀看紀錄、製作額度及回饋與原始 prompt 紀錄保留。
- 舊版已匯入素材會保留原有上架行為；新匯入素材一律先審看。

## 播放器

整個字庫一頁攤開，可捲動；有影片的字排最前面，卡片上標 🎬，看過的字標「看過 N 次」。

- **找字**：上方搜尋框可輸入國字（可一次多個，例如「日月」）、注音或英文意思；按 Enter 直接開第一個結果。篩選：全部／有影片／還沒看過。孩子不會打字時按 **🎲 隨便給我一個**，會優先挑他還沒看過的字。
- **看**：點字卡開啟大畫面，影片或圖片依比例撐到畫面最大、置中、不裁切，直式素材也不會爆版。影片用瀏覽器原生控制列，可暫停、拖曳。
- **瀏覽**：底部「← 上一個／再看一次／下一個 →」依目前清單順序移動；鍵盤 ←／→ 換字、Esc 回字庫，回來時捲動位置不變。
- **次數**：影片播到結尾記一次；圖片顯示 3 秒記一次；沒有素材的字在筆順示範播完記一次；「再看一次」播完再記一次。右上角即時顯示「看過 N 次」，紀錄存在 `data/progress.json`，儲存失敗會暫存於瀏覽器並自動重試。
- **今天看了幾個字**：首頁標題下用星星顯示當日看過的**不同**字數（台灣日期），重播同一個字不會多一顆星。
- **語詞與字的家族**：字頭下方有一條帶狀列。上排是這個字的**三個語詞**（🦖 恐龍、🦕 劍龍、🚰 水龍頭——每個詞都有自己的圖示，目標字放大標色，點一下會唸出來）；手機上這一排放不下三張大詞卡，改成左右滑，右邊會有淡出提示還有更多。下排是**裡面有**哪個他也在學的字、以及這個字**躲在**哪些字裡面，字卡都能點，直接跳過去看那個字。

影片播不動時會出現大播放鍵；檔案壞掉會自動退回字卡。點字卡、翻頁、描字的音效是用 Web Audio 現場合成的，沒有音檔要準備。

## 動畫短片：影片做好之前先看這個

沒有上架影片的字，可以先有一支約 10 秒的**動畫短片**：emoji 角色演一段好笑的小故事，故事裡的東西飛過去變成這個字的筆畫，同時唸「字、字、語詞」。筆畫直接用筆順資料，所以字形一定正確。

- 孩子端把動畫當影片播：字卡標「▶ 影片」、「🎬 有影片」篩選找得到，播完一樣記一次並接筆順描字。
- 順序是 **上架影片 → 動畫 → 圖片 → 字卡動畫**。之後 Gemini 影片上架，就自動改播影片，動畫不用刪。
- Studio 字庫清單會標「有動畫」，選字後最上面可以預覽。`/anim` 是試播頁，可以拖時間軸逐格看。
- 劇本一個字一個檔，放在 `src/anim/clips/<字>.ts`。要新增時跟 Claude Code 說「幫沒影片的字做動畫」，會照 `.claude/skills/char-animation` 的流程挑字、設計、驗證。`npm run anim` 列出還沒有影片也沒有動畫的字，`npm run anim:check` 檢查劇本有沒有常見錯誤。
- 唸字是預先做好的音檔（見下面「唸字的聲音」），音效現場合成。
- 劇本可以用固定造型的**主角**：`public/hero/yang/` 是楊捷睿（本機開源模型畫的，`npm run hero` 產生），
  劇本寫 `emoji: 'hero:yang/drive'`；鏡頭除了推近、震動，還能 `zoom`、`follow` 跟拍。細節在 `.claude/skills/char-animation/SKILL.md`。

## 唸字的聲音

孩子端唸的每一句（字、語詞、字卡的小故事、小鎮的自我介紹、動畫劇本的 cue）都先用這台 Mac 的 `say` 做成音檔，
放在 `public/voice/`（不進 git，每台 Mac 自己做）。好處：唸的時機固定（`npm run anim:check` 會用真實長度驗劇本）、
手機上也出聲、每台裝置聲音一樣。

- **不用手動跑**：`npm run dev` 開機會在背景補缺的句子；Studio 新增、編輯、開放字也會補那個字的幾句；存一份新劇本也會補。
  手動整批重做：`npm run voice`。
- 沒有音檔的句子（字火車臨時接出來的詞、魔法鍋的反應）退回瀏覽器即時朗讀，行為跟以前一樣。
- 預設聲音是 **美佳（Meijia）**。到「系統設定 → 輔助使用 → 朗讀內容 → 系統聲音 → 管理聲音」下載「美佳（進階）」音質會好很多，
  下載後 `npm run voice` 重做一次。換別的聲音：`CPS_VOICE=Sandy npm run voice`（`say -v '?'` 列出有哪些）。
- 想之後換成開源 TTS 或錄爸爸的聲音：只要換掉 `server/voice.mjs` 裡的 `render()`，前端與劇本都不用動。

## 還沒有影片也能玩

字庫裡沒有影片的字走**字卡動畫 → 筆順 → 描字**：emoji 掉下來 → 變形成國字 → 定格並浮出這個字的小笑點（就是 Studio 裡的「設計概念」，點一下可以聽），
接著在田字格裡一筆一畫寫給他看，寫完換他用手指描。所以第一天就有東西看，不用等影片累積。

- **記一次**的時機是**筆順示範播完**，不是描完。描字是加分題，不會因為孩子描不出來就沒有觀看紀錄。
- 整個字描完會有彩帶、音效和「🎉 你自己把這個字寫出來了！」，按鈕變成 **✏️ 再寫一次**。
- 判定對六歲放寬：錯兩次會把正確那一筆用黃色標出來提示，錯四次就當作寫對往下走，不會卡在同一筆。
- **有素材的字也接筆順**：影片播到結尾、圖片停留滿三秒，都會自己換到筆順與描字（先讓彩帶跟音效落在最後一格，約一秒後才換）。也可以隨時按底部的 **✏️ 換你寫** 提前過去，或按 **🎬 回去看** 切回素材；按 **🔁 再看一次** 一律回到素材重看。
- 每個字還有一支純 CSS 背景小動畫（下雨、火焰、光暈、發芽、飛過、彈跳、爆點、閃亮），由字卡的**場景**決定，同一個分類也決定魔法鍋裡兩個字相遇的反應。場景在編輯字卡時選，AI 補齊也會建議；沒選的字用閃亮。這些全部不需要生圖。
- 寫筆順的時候，**他已經學過的那個部件會用藍色寫**，跟帶狀列上那張藍色字卡同一個顏色。例如寫「跑」時前七筆的「足」是藍的，寫「日」時「口」那幾筆是藍的。

### 筆順資料

筆順來自 [hanzi-writer](https://github.com/chanind/hanzi-writer)，資料是 [Make Me a Hanzi](https://github.com/skishore/makemeahanzi)（衍生自文鼎字型，Arphic Public License）。
只把**字庫實際用到的字**抽進 `public/strokes/`，完全離線、不連 CDN。

**不用手動跑**：在 Studio 新增、刪除、還原字，或按「開放給孩子」時，伺服器會自動抽新字的筆順、清掉移除的字。開放一個沒有筆順資料的字時，Studio 會提示；孩子端會自動退回原本的 emoji 字卡動畫，定格幾秒一樣記一次。要手動重抽也可以跑 `npm run strokes`。

### 長得像的字（挑干擾字要避開的）

餵大怪獸、跳石頭過河、小偵探都要挑一個「不是答案」的字當干擾。挑到長得像的字，
他找錯就不是因為不認得，而是被騙——小偵探更慘，整個遊戲就是看字形，左邊畫完一模一樣還要他猜。

哪兩個字算像，兩種來源：

1. `data/parts.json`：其中一個藏在另一個裡面，或有共同的部件（口 跟 日、目 跟 田）
2. `src/play/alike.ts`：**前幾筆的筆順中線幾乎重疊**，也就是共用一個偏旁（蜂／蝶、河／湯、跑／跳、飯／餃）

第二張表是算出來的：筆順資料裡每一筆都有中線座標（0–1024），共用偏旁的字前幾筆平均距離會掉到
55 以下（火跟水是 409、日跟目是 74）。拆字表只記得到「部件本身也在字庫裡」的關係，
「虫」「氵」不在字庫，就只能靠這個。

字庫加字之後跑一次 `npm run alike` 重算（沒重算只會少擋幾對，不會壞掉）。

### 字的家族（哪個字裡面有哪個字）

`data/parts.json` 記錄「跑裡面有足」這種關係，以及那個部件佔掉哪幾筆（決定藍色標在哪）。拆字資料同樣出自 Make Me a Hanzi。

跟筆順一樣，**字庫一變動就自動重算**，孩子端重新整理就看得到。拆字資料第一次要連網下載（之後讀 `node_modules/.cache` 的快取）；沒網路時家長的操作照樣完成，Studio 會提示字的家族這次沒更新，下次變動時再算。要手動重算可以跑 `npm run parts`。

只收**字庫裡已經有的字**當部件，孩子點下去才不會撲空。有兩道防呆：部件佔的筆數必須等於那個字本身的筆數，對不上就丟掉（例如「果」裡的「田」少一筆，就不會標）；另外有一小張人工排除表 `SKIP` 寫在 `server/char-assets.mjs` 裡，擋掉拆得出來但不適合教的組合（像「火裡面有人」），要改直接編那張表，再跑一次 `npm run parts`。

## ⭐ 每個字五顆星

同一個字在樂園裡有五個地方可以去，每去過一個就多一顆星：**看過 👀、自己寫出來 ✏️、餵大怪獸時自己認出來 🍽️、
在詞裡把它補上 🧩、在魔法鍋裡把它變出來 🧪**。集滿的字在字庫裡戴皇冠、鑲金邊。

- 星星完全**從已經在記的紀錄算出來**（`shared/domain.mjs` 的 `STAR_DEEDS`／`starIndex`），沒有另外存一份，
  所以舊的進度檔一打開就有星星，也不會有「紀錄有、星星沒有」對不起來的情況。
- 不是每個字五顆都拿得到：魔法鍋只變得出「裡面有他也在學的字」的字，詞語拼圖只出畫得出來的詞。
  拿不到的那顆不列出來也不算進滿星（`src/play/stars.ts` 的 `deedsFor`），不然他會永遠差一顆。
- 集滿的字在字庫上方多一個 **👑 集滿星星** 的篩選（一個都還沒有的時候不出現）。
- 字卡頁右上角那排星星點開來，會說還差哪一顆、要去哪裡拿，**按一下直接過去**。
  魔法鍋跟詞語拼圖他不會自己想到要去，但「『火』還差這一顆」看得懂。
- 沒玩過的新玩法在首頁入口亮一顆 🆕，進去一次就不亮了（記在這台裝置，`src/play/seen.ts`）。
- 拿到星星的那一下在 `PlayApp`（`.star-pop`）：任何一個遊戲拿到都會跳，集滿五顆放彩帶與變身音效。

## 🎁 星星寶箱與夥伴

星星本來只會一直累積，沒有「拿到東西」的那一刻。現在每 20 顆星星開一個寶箱，
箱子抖三下再爆開，跳出一位新夥伴（`src/play/partners.ts`，十八位，第一位是楊捷睿自己）。

夥伴不是只放在圖鑑裡好看：**他們就是「跳石頭過河」的主角**，開到誰，誰就會在河邊等他。
小鎮上方那一排是他收集到的夥伴，最後一格的 ? 寫著還差幾顆星星；點一位就直接去過河。

點首頁的星星存摺會打開 **「我的東西」**：星星、夥伴、小鎮住了幾個字、詞語圖鑑、魔法鍋變出幾個字、
星星集滿的字，全部攤在一起，按一下就去那個地方（`src/play/Mine.tsx`）。
他收集的東西本來散在六個遊戲裡，每個都要進去才看得到。

誰解鎖了完全由「總共幾顆星星」算出來，沒有新的進度欄位——換裝置、重開都一樣。
（所以如果之後把 `data/progress.json` 還原成比較少的紀錄，夥伴數也會跟著變少。）

## 今天的三件事

他可以玩的地方變多了（七個），但「今天到底要做什麼」還是沒人講。首頁字卡上方給他三件小事：
**看 3 個字**固定在第一件（其他玩法都只考他看過的字），另外兩件照日期輪
（自己認出 3 個字、拼好 2 個詞、自己寫 1 個字、魔法鍋變出 2 個字）。

- 每件都有進度與一個勾，三件都做完放彩帶說「今天的三件事都做完了！」。
- **沒有失敗、沒有倒數、沒做完也不會怎麼樣**——這是給六歲的目標，不是作業。
- 規則在 `src/play/today.ts`，全部從已經在記的紀錄按台灣日期算（哪一筆是今天做的），
  沒有新的進度欄位；同一天重算結果一樣，換一天才換題目。

## 首頁那隻角色：今天可以做什麼

六歲打開 app 不會自己想「今天該做什麼」：字卡攤開兩百多張、七個遊戲一排按鈕，他就點最熟的那個。
所以首頁站了一隻角色，看他的紀錄挑**一件現在最值得做的事**說出來，按一下直接過去。

規則有先後（`src/play/nudge.ts`，純函式、有測試）：今天還沒看字 → 從來沒去過的地方 →
有一堆字到期該複習 → 快開到下一個寶箱（差三顆以內）→ 有字差一顆星就滿 → 不然就講他收集到幾顆星星。
每一條都只用已經在記的紀錄算，沒有新的進度欄位；做完一件事它就換下一句。

「從來沒去過的地方」是特地加的：他的紀錄裡魔法鍋與字火車都是 0 次——不是不好玩，是從來沒被帶進去過。

**他還不會讀字**，所以角色旁邊有一顆 🔊，按了會把那句話唸出來（按角色本身才是過去）。
固定的那幾句在 `shared/voice-lines.mjs` 裡，開機就做好音檔；帶數字的那幾句
（「有 5 個字可以再認一次」）每次都不一樣，退回瀏覽器朗讀。

## 看完之後還有地方去：我的小鎮、魔法鍋、字火車、餵大怪獸、跳石頭過河、小偵探、詞語拼圖

首頁上方有幾個大按鈕。它們讓孩子有理由**重複**看、重複寫、重複認同一個字，而不是看一次就滑走。

### 🏡 我的小鎮

- 描完一個字（整個字，不是只看完筆順示範），這個字就**搬進小鎮**，身體是**他自己寫的筆跡**，不是字型。
- 畫面左下會跳出「🏡『火』搬進你的小鎮了！」，點下去直接到小鎮。
- 再寫一次會長大一號，筆跡換成最新的一次；寫到五次戴皇冠 👑。
- 點居民會跳一下、唸「我是火！火車的火」，泡泡裡的 **▶ 看我** 會打開那個字。最新搬來的站最前面，標「✨ 新來的」。

### 🧪 魔法鍋

把字丟進鍋子，按 **🪄 攪一攪**。沒有「錯」，每次都會發生一點事：

| 丟進去 | 會發生什麼 |
| --- | --- |
| 一個字 | 變成一個**藏著它的字**：口 → 日／足／目／中…，優先給還沒發現的，所以同一個字可以一直丟 |
| 兩個字剛好湊成一個字 | 變出那個字：口＋犬 → 器、人＋王 → 金 |
| 一個字本來就在另一個字裡 | 「🔍 找到了！口躲在日裡面」 |
| 其他組合 | 依兩個字的場景冒出好笑的反應：火＋水 → 💨 冒煙、雨＋花 → 🌸 長出小花 |

變出來的字會一筆一畫寫出來，**丟進去的那個字用藍色**（跟筆順裡的藍色同一個意思）。下方「📖 魔法圖鑑」記錄發現過的字；還沒發現的格子是 ？，右下角小字提示從哪個字開始丟。

配方直接來自 `data/parts.json`，開放新字之後，鍋子就會自動多出新的變化。兩個場景相遇的反應表在 `src/play/brew.ts`。

### 🍽️ 餵大怪獸

其他玩法都是「看」和「照著寫」；這裡是唯一要他**自己把字認出來**的地方（研究上「隔幾天再想起來」比一直重看記得牢）。

- 大怪獸有節奏地點菜：咚、咚 →「我要吃火！」→「火！」→「火！」，題目字一次唸三遍；他還沒點，隔幾秒整段再唸，最多提醒兩次。🔊 可以隨時再聽。
- 盤子上兩張卡片**只有字、沒有圖也沒有顏色**，要靠讀字。
- 找對了：卡片上變出圖、唸一個有這個字的語詞（每輪換一個畫得出來的詞），圖飛進怪獸嘴巴。一輪 5 道。
- 自己找到的字會把肚子越撐越大（旁邊三格量表），塞滿 3 個就發生一件大事，四種輪流、輪完才重複：砰！炸成星星、吃太飽睡著打呼、打嗝把自己噴上天、轉一圈變彩虹怪獸。靠提示才吃到的照樣吃，但不算進肚子。結局在 `src/play/finales.ts`。
- 找錯不是錯：怪獸說「這是水耶！」，那張翻開給他看是什麼，正確的那張發亮，再點一次一定吃得到。
- **刻意不難**：永遠二選一；另一張挑長得很不一樣的字（不會拿「目」配「日」）；只考他看過的字；第一題是他看最多次的字暖身。
- 每個字記一個「記住程度」：第一次就找對 → 升一級，隔 1、2、4、7、15 天再考；找錯 → 降一級、今天再考。每輪最多兩個該複習的字，其他是新的。首頁入口顯示「認得 N 個字」。
- 規則在 `shared/domain.mjs` 的 `recall`，出題與挑另一張卡在 `src/play/dishes.ts`。
  **跳石頭過河與小偵探共用這一整套**：一個字的記住程度只有一份，在哪個遊戲認出來都算數。

### 🚂 字火車

- 從貨架（有影片的字）接 2～4 個字開火車，一節一節播每個字的影片，最後整個詞唸一次。沒有對錯，豬飛走也很好笑。
- 接出字卡語詞裡真的有的詞（火車、機器人），會跳出「🚂 真的有這個詞！」，開完火車最後也放出那張圖。
- 接到一半，能接成真詞的下一個字在貨架上發亮（選了火，車、山、星會亮）。只是提示，照樣可以亂接。規則在 `src/play/words.ts` 的 `realWords`、`nextChars`。

### 🌊 跳石頭過河

主角站在這一岸，對岸有牠想要的東西（小老鼠要起司、海盜要寶藏，八位輪著來）。
河上一排一排的石頭，每顆上面一個字，聽到「跳到『火』！」就踩那一顆。

- 其他玩法都是「答對一題、再答一題」；這裡多了一件**看得到自己走到哪、還有多遠**。
  上面那條路線圖是岸 → 五顆石頭 → 對岸的東西，跳對的留一顆星，靠提示的留一塊石頭。
- 踩錯不是錯：那顆石頭噗通沉進水裡，說清楚「這是水耶！」，對的那顆發亮，再跳一次一定跳得到。
- 上岸之後，剛剛踩過的五顆石頭留在河上變成他走過來的路，自己認出來的那幾顆鑲金邊；
  五顆都自己跳對會先說一句「一次都沒掉下去！」。
- **一位夥伴一種天色**（白天、黃昏、下雪、晚上），換一位夥伴整條河就換個樣子——
  同一個玩法玩第三次還有新鮮感，靠的是這個。天色只換 CSS 變數，版面一行都沒動（`partners.ts` 的 `skyFor`）。
- 考的能力跟餵大怪獸一樣（聽到字自己把它認出來），所以**出題、挑干擾的字、記紀錄全部共用那一套**
  （`src/play/crossing.ts` → `dishes.ts`，記的是 `recall` 事件）：同一個字的記住程度只有一份，
  在哪個遊戲認出來都算數，間隔複習照樣排得準，也一樣算進「認得 N 個字」跟 ⭐ 星星。

### 🔍 小偵探

一筆一筆把字畫出來，猜猜我是誰——**越早認出來越厲害**（「只看了 2 筆就猜到！」）。

- 其他玩法考的是聽到字找出來（餵大怪獸、跳石頭過河）跟讀懂詞（詞語拼圖），
  這裡是唯一在練**看字形認字**的地方：沒有聲音提示，只有線條。
- 猜錯那張淡掉留在原地（他看得出自己排除了什麼），筆畫繼續畫；全部畫完還沒猜到就把答案指出來
  （從出題算起至少給他五秒——「一」只有一筆，650ms 就畫完了）。
- 一兩筆就猜到會先喊一句「哇！好厲害！」再唸那個字。
- 筆順資料（`public/strokes/`）直接畫成 SVG，一筆一個 `<path>`，露幾筆就畫幾筆——
  不用 hanzi-writer 的動畫，因為這裡要的是「停在第幾筆」。筆畫多的字畫快一點，整個字大約 8 秒畫完。
- 出題、挑干擾的字、記紀錄都跟餵大怪獸共用（`src/play/guessing.ts` → `dishes.ts`，記 `recall`）。
- 換題後半秒內不收答案：手指還停在上一題的卡片上，不要讓他誤點就答掉下一題。

### 🧩 詞語拼圖

每個字的 3～4 個語詞平常只在字卡上點來聽；這裡要他**在詞裡把字認出來**，同一個字一次次出現在不同的詞裡（生日、日出、日記），字才會跟生活連起來。

- **補字**：上面是詞的圖（先是灰灰的影子），中間是缺一個字的詞「生 □」。先唸「生日」再說「生日的日」，從字卡裡找出來補上；補對了，影子變成彩色跳起來。
- **看詞找圖**：整個詞寫出來、圖是空的虛線框，問「哪一張圖是這個詞？」，讀懂了把對的圖卡放上去。只出詞裡每個字都看過的詞，一輪最多兩題；沒點或點錯才把詞唸出來當提示。
- 找錯不是錯：翻開那張說它是什麼，對的那張發亮；這個詞隔兩題再考一次。上次要靠提示才拼好的詞，下一輪先回來複習（最多兩個）。
- 只用他看過的字；沒拼過的詞先上，同一個字的新詞裡畫得出來的具體詞先上。字卡語詞裡太難或只是文法的詞（你的、快捷），以及圖畫不出意思的詞（中間、小心），在 `src/play/puzzles.ts` 的 `SKIP_WORDS`、`NO_PICTURE` 兩張表，要調整直接改。
- 難度跟著他走：第一下就找對不到一半只放兩張卡；八成以上放一張長得像的字（日、目）或有共同字的詞（火車、火山）。
- 出題的是一隻浣熊（其他六個玩法都有一隻角色在旁邊，只有這裡本來沒有）。
- 拼好的詞收進 **📖 詞語圖鑑**：一個字一排，拼好的點了會唸，還沒拼的只露影子（火？）。字卡頁的語詞旁邊也會標 🧩。
- 紀錄是 `puzzle` 事件（`shared/domain.mjs` 的 `solvePuzzle`），進度在 `progress.puzzles`；每個詞多一句「○○的○」預先做音檔。

## 家長看學習小結

Studio 沒選字時，主區是**孩子的學習小結**：看過幾個字、認得幾個（今天該複習幾個；餵大怪獸、跳石頭過河、
小偵探記的是同一種紀錄）、收集了幾個詞、小鎮居民、⭐ 星星與夥伴（他自己在追的那條線）；常找錯的字、還要再練的詞（點字直接打開）；以及「今天可以問他：你在哪裡看過🌋火山？」——拿他最近收集的詞，把字跟生活連起來。統計在 `src/studio/summary.ts`，只讀不改。

## AI Prompt 生成

Studio 呼叫本機已登入的 CLI，讓模型從字義、家長方向、最近回饋、前三個創意版本與受喜愛的範例重新設計。保留 8 秒、清楚繁體字、至少 3 秒最後定格、台灣華語發音等要求，但登場、形變方式與節奏由模型決定，不再固定套三段模板。

每支片圍繞**一個安排清楚、一眼看懂的肢體笑點**（模板 v8）：誰想幹嘛 → 助跑 → 撞上去那一下 → 暈頭轉向的笑臉，撞出來的東西落成筆畫。
套路有 12 種（衝撞、追逐、友善對打、拔河、彈射、疊高倒、滑壘撞飛、彈跳連鎖、用力過猛、以小搏大、偷偷摸摸被抓包、骨牌連鎖），
主角 17 位（調皮小老鼠、豬探長、浣熊助手花生、拉布拉多警長、玩具機器人、大怪獸、賽車、橡膠恐龍、披風英雄、布忍者⋯⋯），
需要對手的套路再配一位對手；三者都照字的順序輪轉（`server/prompt-generation.mjs` 的 `leadCast`／`rivalCast`／`gagPattern`），
所以整個字庫不會都是打架、也不會都是同一個主角。改 `data/prompt-template.json` 的 `castRoster`／`gagPlaybook` 就能換卡司與套路。
角色一律是原創造型，不寫任何品牌或授權角色的名字；畫面不出現真人與兒童，最終 prompt 不帶觀眾年齡描述，旁白只在畫面外發聲。笑點在最後定格前完成，保留清楚字形與發音。

發音採 **單字 → 單字 → 簡單詞彙**：單字唸兩次，每次稍作停頓，再唸一個包含該字的日常詞彙，例如「人、人、機器人」或「木、木、木頭」。AI 選擇適合孩子、同讀音與字義的兩到三字詞彙，目標字可在詞彙的任何位置，並把確切台詞寫進 prompt；唸完詞彙就結束。詞彙只唸出來，畫面仍只顯示目標國字。此規則套用到新生成的 AI prompt 與備用模板；舊 prompt 需重新生成，既有影片與播放器的系統朗讀不會自動改變。

- **Codex**：`codex exec` 非互動模式，讀取既有 CLI 登入。參考 [官方非互動模式文件](https://learn.chatgpt.com/docs/non-interactive-mode)。
- **Claude Code**：`claude --print`，使用既有 Claude 登入。
- **Google agy**：`agy --print`，使用 Antigravity CLI 登入；模型名稱可用 `agy models` 查詢。
- 模型欄位留空時使用工具的預設模型。Codex 的生成工作不載入使用者 `config.toml`；若平常有自訂模型，請在 Studio 明確填入。顯示的模型優先採 CLI 回報值，未回報則顯示指定值或「工具預設模型」。
- **換個創意，重新生成** 每次會再次呼叫 CLI，保留舊版本，並參考它們避免重複。可從版本選單切回。
- 複製與刷新不會重新呼叫模型。失敗／取消／逾時保留上一份結果，不會偷偷改用模板。
- 生成 prompt 使用 CLI 帳號額度；與你手動記錄的每天三支**影片**額度分開。

CLI 在暫存工作目錄執行。Claude 關閉工具、客製化與 MCP；Codex 採唯讀模式；agy 採 plan 與 sandbox。程式以固定執行檔及參數陣列啟動，不把提示文字交給 shell。沒有使用跳過權限的旗標。逾時或取消會終止子程序。

若找不到 CLI，先在終端機安裝並登入，再重新啟動 `npm run dev`。可用 `CPS_CODEX_BIN`、`CPS_CLAUDE_BIN`、`CPS_AGY_BIN` 指定執行檔的絕對路徑。此設定放在啟動服務的環境變數，不會讓瀏覽器送任意命令。

命令列也能用：

```bash
npm run prompt -- 山 --provider codex
npm run prompt -- 雲 --provider claude --direction "像玩具劇場，有一個小驚喜"
npm run prompt -- --today --provider agy
npm run prompt -- 日 --provider codex --preview # 真實 AI 呼叫，只預覽、不寫字庫
npm run prompt -- 山 --template                # 明確使用舊式本機模板
```

CLI 預設生成並保存版本，新國字會自動加入字庫。`--today` 與 Studio 的一鍵批次跑同一份當日建議清單，差別是 CLI 會佔住終端機、也不會跳過已有最新 prompt 的字；它不代表影片已送出，不會扣影片額度。`--preview` 不寫字庫，但仍使用模型額度。需要記錄影片送出時，回到 Studio 選字並複製已存版本。

需要完全離線時，可明確選 **本機模板（備用）**。它使用 `data/prompt-template.json` 和手寫概念，沒有 AI 創作。新版 AI 生成邏輯在 `server/prompt-generation.mjs`，三種 CLI 介接在 `server/ai-cli.mjs`。

## 回饋迴路

看完在 Studio 按標籤（他超愛 / 字看不清 / 太吵太亂 / 形變沒看懂 / 太快）。
四種負面標籤都會標記 `needsRedo`。AI 版本收到新回饋後會標示需更新；按重新生成，模型根據問題重新設計，生成前也可在「這次想怎麼拍」補具體方向。既有 prompt 不會被回饋直接改寫，保留當時送出的真實文字。

正面回饋不會取消已有的重做需求。修訂後的新影片確認上架，才解除已處理的重做標記；圖片或舊版本不能清掉較新的負面回饋。重做可立即從字庫選取，隔日建議會優先安排待重做的字。

> AI 可參考有「他超愛」回饋且有 prompt 紀錄的其他字；目前以文字概念與回饋為依據，不會自動看影片或訓練模型。舊式模板備用模式仍使用固定的標籤修訂規則。

## 檔案放哪

```
data/characters.json       字庫 + 狀態 + 每日製作紀錄（進 git，可 diff）
data/prompts/<字>.json     每個字保存過的 AI prompt 版本全文（進 git）
data/prompt-template.json  prompt 三層
data/progress.json         觀看紀錄、小鎮居民（他的筆跡）、魔法鍋發現、字火車的詞、餵怪獸記住程度、詞語圖鑑（不進 git）
media/                     影片圖片（不進 git，靠 Google Drive 同步）
public/strokes/            筆順資料，字庫變動時自動更新（進 git，離線可用）
data/parts.json            哪個字裡面有哪個字，字庫變動時自動重算（進 git）
```

觀看完成、描字搬進小鎮、魔法鍋發現、字火車組詞、餵怪獸、拼圖都採用唯一事件編號避免重複記錄；重播看完會增加次數。尚未成功儲存的事件會留在瀏覽器暫存，重試或重開後再同步。伺服器記得的事件編號保留 60 天後自動清掉，`progress.json` 不會一直長大；舊格式的檔案第一次載入時自動升級（`server/progress.mjs`）。

## 孩子端的程式怎麼分

```
src/play/PlayApp.tsx     外框：載入字庫與進度、現在在哪個畫面、記紀錄
src/play/games.tsx       遊戲清單（小鎮、魔法鍋、字火車、餵大怪獸、跳石頭過河、小偵探、詞語拼圖）：首頁入口按鈕與網址都從這裡來
src/play/route.ts        網址 #/lab?c=口 ↔ 畫面；手機的「返回」會關字卡、回上一個畫面
src/play/Viewer.tsx      看一個字；流程狀態在 viewerFlow.ts，播什麼在 source.ts
src/play/VideoPlayer.tsx 播上架影片（觀看層與字火車共用）
src/play/ui.tsx          共用小元件：上方列、彩帶、大播放鍵、字的顏色
src/play/styles/*.css    一個區域一個樣式檔，play.css 依序接起來
shared/play-events.mjs   孩子端紀錄的種類與規則（畫面與伺服器共用同一張表）
shared/voice-lines.mjs   固定台詞的句型（畫面與預先做音檔共用）
server/progress.mjs      progress.json 的讀寫、格式升級、存一筆紀錄
```

### 加一個新遊戲

1. 畫面元件 `src/play/<Game>.tsx`，上方列用 `ui.tsx` 的 `SubBar`，字的顏色用 `hueOf`；樣式放 `src/play/styles/<game>.css`，在 `play.css` 最後接上。
2. 要記進度：規則寫成純函式放 `shared/domain.mjs`；`shared/play-events.mjs` 加一種紀錄（伺服器自動多一條 `POST /api/<種類>`）；`src/types.ts` 的 `Progress` 加欄位、`shared/play-events.d.mts` 的 `PlayEvent` 加一型。
3. 有固定台詞：`shared/voice-lines.mjs` 加句型並放進 `linesForEntry`，音檔會自動預先做好。
4. `src/play/games.tsx` 的 `GAMES` 加一筆，首頁就多一顆入口按鈕，網址是 `#/<id>`。
5. 規則的測試放 `tests/`（參考 `magic-pot.test.mjs`、`word-puzzle.test.mjs`）。
6. 在瀏覽器試玩前先備份 `data/progress.json`：孩子端的紀錄送不出去時會留在瀏覽器暫存，之後任何一次開頁都會補送進真實紀錄。

## 驗證

```bash
npm test          # 隔離暫存字庫，驗證日期、額度、回饋、上架、孩子端紀錄 API 與進度檔升級
npm run build     # TypeScript + 前端編譯
npm run strokes   # 手動重抽筆順（平常 Studio 增刪、開放字時會自動做）
npm run parts     # 手動重算字的家族（改了 SKIP 排除表之後；第一次需要連網）
npm run alike     # 重算「長得像的字」（字庫加字之後）
npm run dev:test  # http://127.0.0.1:5181/studio，獨立測試字庫，Ctrl+C 後清理
```

本機操作請用 `npm run dev`；`build` 只檢查與產生前端檔案，`preview` 未提供檔案操作 API。
